3 שיפורי SEO

איפה ב-WP: בכל פוסט/עמוד, למטה יש תיבת Yoast SEO. שם עורכים את ה-Meta Description ו-Title.

Meta Description לדף הבית

נוכחי: "תיכון יזמי, חדשני ורלוונטי" (קצר מדי)

מומלץ:

תיכון מקצועי בירושלים | מגמות מחשבים, אוטוטק, עיצוב שיער | בגרות מלאה + תעודת מקצוע + ניסיון תעסוקתי | הרשמה לתשפ"ז

Alt Text לתמונות

רוב התמונות באתר ללא תיאור alt. בכל עריכת פוסט, ללחוץ על התמונה ולהוסיף תיאור.

דוגמאות:

  • תמונת סליידר 1: "תלמידים באורט בית הערבה בשיעור מעשי"
  • תמונת סליידר 2: "בית ספר אורט בית הערבה ירושלים — מבט מבחוץ"
  • תמונת מגמת מחשבים: "תלמיד עובד על מחשב במגמת ניהול רשתות"

דף נפרד לכל מגמה (SEO חדש)

כל מגמה צריכה דף נחיתה עם מילות מפתח ייעודיות כדי שמי שמחפש ימצא:

  • מגמת מחשבים: "לימודי מחשבים ירושלים", "קורס ניהול רשתות תיכון"
  • מגמת אוטוטק: "לימודי מכונאות ירושלים", "מכונאות רכב תיכון"
  • מגמת ביוטי: "לימודי עיצוב שיער ירושלים", "ביוטי טק תיכון"

6 שיפורי עיצוב וביצועים

בינוני צבעים

הפלטת הנוכחית צעקנית: ורוד חזק + טורקיז + סגול. מומלץ לצמצם ל-2 צבעים רגועים (בהתאם למיתוג החדש).

בינוני ביצועי טעינה

  • הוספת loading="lazy" לתמונות (דורש Admin)
  • דחיסת תמונות — רובן 2560px, צריך להקטין ל-1200px
  • צמצום פונטים מ-Google Fonts ל-2-3 משקלים בלבד
  • הסרת תוספים כבדים שלא בשימוש (FortVision campaign)

נמוך החלפת תבנית

התבנית Poza מבוססת Bootstrap 3.2 (מיושן מאוד). בשלב המיתוג לשקול מעבר לתבנית מודרנית. דורש Admin.

7 הרשאות חסרות — דורש Admin

המשתמשת הנוכחית (golan liron) היא Editor, לא Administrator. לכן אי אפשר:

  • להוסיף משתמשים חדשים
  • לערוך תפריטים (Appearance → Menus)
  • להתקין/להסיר תוספים
  • לשנות תבנית
  • לערוך CSS
  • לערוך ווידג'טים (Widgets)

מה לעשות: לפנות ל-IT של אורט ולבקש:

  1. הרשאות Administrator למשתמשת שלך (או למייטל)
  2. או לחלופין — Application Password שמאפשר גישה דרך API
