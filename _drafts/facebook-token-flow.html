תרשים זרימה: יצירת טוקן פייסבוק לצמיתות

מדריך שלב אחר שלב ליצירת Page Access Token שלא פג תוקף
הטוקן הנוכחי פג היום! יש לחדש עכשיו
1

כניסה ל-Graph API Explorer

developers.facebook.com/tools/explorer
  • בחירת אפליקציה: "massage"
  • בחירת הרשאות:
pages_manage_posts pages_read_engagement pages_show_list
  • לחיצה על Generate Access Token
תוצאה: Short-lived User Token (תוקף: 1-2 שעות)
2

המרה ל-Long-lived User Token

  • שליחת קריאת API לפייסבוק:
GET /oauth/access_token
  ?grant_type=fb_exchange_token
  &client_id=2175318433273432
  &client_secret=APP_SECRET
  &fb_exchange_token=SHORT_TOKEN
  • APP_ID: 2175318433273432
  • APP_SECRET: נמצא בהגדרות האפליקציה
  • SHORT_TOKEN: הטוקן שקיבלתם בשלב 1
תוצאה: Long-lived User Token (תוקף: 60 יום)
3

קבלת Page Token לצמיתות

  • שליחת קריאת API:
GET /me/accounts
  ?access_token=LONG_LIVED_USER_TOKEN
  • מחזיר טוקן נפרד לכל דף שמנוהל
  • הטוקן נוצר מתוך Long-lived User Token ולכן הוא לא פג לעולם
תוצאה: Page Access Token (לצמיתות - לא פג לעולם!)
4

עדכון mcp.json

  • פתיחת קובץ ההגדרות:
~/.claude/mcp.json
  • מחליפים את הערך של FB_USER_TOKEN בטוקן החדש
  • שומרים את הקובץ
  • מפעילים מחדש את Claude Code
תוצאה: חיבור Facebook API פעיל ומוכן לשימוש
