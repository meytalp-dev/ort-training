## הזרימה בכל "רַעֲנֵן"
1. `git pull`. זהה מה השתנה: `git status --short *.html` (עבודה לא-מקומטת) **וגם** `git log --oneline -8` (סוכנים שדחפו קומיטים).
2. הרץ שרת פעם אחת: `python -m http.server 8777` והשאר רץ.
3. לכל מסך שהשתנה — בדוק את §1+§6 (הרשימה למטה). **בדוק בעצמך מול הקוד — אל תסמוך על הדיווח-העצמי של הסוכן.** אותה הטיה של LLM גורמת לסוכן "לראות" שהוא סיים כשלא.
4. הצג למיטל לכל מסך: קישור לחיץ `http://localhost:8777/<file>` + שורת-סיכום.
5. **נקי →** `status:'done'` ב-`migration-data.js` + commit+push. **לא נקי →** `status:'fail'` + `failNote` מדויק, אל תסמן done, החזר ליצרן.

## מה לבדוק בכל מסך (grep — כלי Grep, לא bash-grep)
```
grep -nE '(background|color):[[:space:]]*#[0-9a-fA-F]{3,6}' <file>   → חייב ריק (hex מותר רק כ-fallback ב-var() וב-SVG)
grep -c 'linear-gradient' <file>                                    → 0 (חריג: גרדיאנט נושא-מידע מתועד)
grep 'tokens.css?v=2' לפני 'components.css'
data-layer: shell→פטל · learning→בלי data-layer (דיו). ודא נכונות מול §0/§8.
```

## 🔴 שלוש נקודות עיוורות שצרבו אותי — אל תחזור עליהן

**1. הלוגו — הכי מסוכן.** קבוצות `style="stroke:var(--brand)"` יכולות להיות **הלוגו הישן (שלושת-הגלים)**, לא הנקודה. אל תסמן "סימן תקין" בלי לוודא את ה-`d` בפועל:
- **גלים ישן (פסול):** `d="M10 6 C12.5 8.26..."` / `C5.5 9.74`
- **נקודה חדש (תקין):** `circle cx=... stroke="var(--brand)"` + `d="M11.5 12H3"` (או ב-§5: `d="M28 10H3"`)
```
grep -c 'M10 6 C12.5' <file>   → חייב 0
```
בדוק גם **פאביקון**: ישן = `%3Crect...%3Cpath d='M8 11h12'` · חדש = `circle cx='16'...`. וגם `logo-full`, `logo-symbol`, `topbar-m__brand`, לוגו-מוק inline.

**2. טורקיז דקורטיבי (§4) — "הכי קל לפספס".** לא רק כפתורים. סרוק **כל** `var(--brand*)` ותפריד:
- **לגיטימי (השאר):** הסימן (SVG הנקודה) · החוט/`.seq-rule`/`.cov-rail` (קו+נקודה) · הילת-פוקוס (`--brand-bright`, `--shadow-brand`).
- **דקורטיבי (פסול → תקן):** אייקונים (`.scard__ic`, `.val-static svg`, `.school-pick svg`, role-icons) · שבבים/תגיות (`.lock-tag`, role-chip) · באדג'ים (`badge--brand`) · מסגרות-hover/active · באנרים/הערות.
  - תיקון: אייקון/אווטאר/זהות → `var(--ink-soft)` ניטרלי · פעיל/hover/באנר → `var(--action*)` (מודע-שכבה).

**3. אל תסמוך על דיווח-סוכן.** מסך יכול להיות "כבר מוגר" אך עדיין `todo` בלוח — אמת ואז הרם את הדגל. וסוכן יכול לדווח "סיימתי" כשהשאיר לוגו ישן / שבב טורקיז.

## הבחנות שכבר הוכרעו (אל תסמן אותן ככשל)
- `→ / ←` **בתוך משפט** = תוכן זרימה ("טיוטה → אישור → פורסם") — **לא לגעת**. רק חץ עומד-לבד כקישוט-ניווט = SVG.
- `✓ / ✗ / —` = גליפים טיפוגרפיים (לרוב מיוצרים ב-JS) — **קבילים**, לא אימוג'י ציורי. אל תדרוש SVG (וגם אסור לך לגעת ב-JS).
- `🚫` בהערות-קוד = קונבנציה קיימת (גם ב-tokens.css) — קביל.
- **אימוג'י בתוך מוקאפ-וואטסאפ** (`daily-report.html` — טקסט ההודעה 🟢🔵🟠👈) = חריג מוצדק שהוכרע 9.7 — קביל *רק* שם. בשאר הממשק — SVG. גם טורקיז במוקאפ-הטלפון (`.phone__bar` וכו') = המחשת-WhatsApp, לא צ'רום המערכת — הפעל שיקול-דעת, אל תסמן ככשל אוטומטית.
- **טוקן מומצא:** אם סוכן כתב `var(--X, #hex)` ו-`--X` **לא קיים** ב-`tokens.css` (למשל `--status-good-ink`) — זה ערך-מומצא. או להוסיף ל-`tokens.css` (מיטל מאשרת, **בלי לבמפ** — fallback מכסה) או fail.
- **מקרא קטגורי** (`--type-video/quiz/...`, נקודות-מקצוע, `--favorite`) = צבע נושא-מידע — לגיטימי גם אם טורקיז-משפחה. הערת-מובחנות בלבד אם שני גוונים כמעט זהים.
- **§8 סיווג:** `teacher-dashboard`/`parent-weekly` → **למידה** · `educator-pulse` → תפעול. `learning`+`register:ops` זה שילוב תקין (דיו + צפיפות).
- **§4 לדשבורד מעוצב** (hero/KPI/דונאט): רק החלקים ה-CSS-בטוחים (כותרת 22px, הסרת צללים, נורת-מצב). **לא** רה-סטרקטור — זה שובר "אל תיגע במבנה".
