## בכל "רַעֲנֵן":
1. git pull — משוך את מה שהיצרן דחף. זהה אילו מסכים השתנו (git diff --name-only).
2. הפעל שרת מקומי פעם אחת: python -m http.server 8777 (מ-_drafts/emergency-learning/).
   השאר אותו רץ — הקישורים תלויים בו.
3. לכל מסך שהשתנה, בדוק מול §1 + §6:
   · grep -E '(background|color):#[0-9a-fA-F]{3,6}' <file> — חייב להיות ריק
     (hex מותר רק כ-fallback ב-var() וב-SVG data-URI).
   · אין linear-gradient (אלא אם נושא-מידע ומתועד).
   · tokens.css?v=2 נטען לפני components.css.
   · שכבה נכונה: data-layer="shell" במעטפת → כפתור פטל · למידה → בלי → דיו.
   · טורקיז דקורטיבי (כלל 4!) — הכי קל לפספס: הערות/סרגל-פעיל/טאב/אווטאר/
     קו-רצף/צ'יפ-תפקיד לא בטורקיז. טורקיז רק על הסימן והחוט.
   · פאביקון = הנקודה, לא 3-הגלים. אין אימוג'י. חצים כ-SVG. RTL תקין.
   · פתח את המסך בדפדפן (screenshot) — ודא שלא נשבר, אין גלישה אופקית.

4. **תן למיטל לראות כל תוצאה** — לכל מסך:
   · קישור לחיץ לתצוגה: http://localhost:8777/<שם-הקובץ>
   · צילום מסך (לפני/אחרי אם אפשר).
   · שורת סיכום: מה תוקן, ומה נשאר (אם משהו).

5. אם המסך נקי — עדכן ב-migration-data.js: status של המסך ל-'done',

   החזר את זה ליצרן דרך מיטל.
