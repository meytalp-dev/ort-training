## 0. למה המסמך הזה קיים

זה **בנק הנוסחים** של כל טקסט שהתלמיד רואה במסך שלו — ברכות, תגובות check-in, חיווי "המורה ראה", עידוד, סיום משימה, חזרה אחרי היעדרות, ושגיאות. כל מסך בעולם התלמיד (`student-home.html` וכל מסך תרגול) שואב מכאן.

**הקול — בגובה העיניים של בן 16:**

| כן | לא |
|-----|-----|
| חם וישיר, כמו מבוגר שסומכים עליו | ילדותי — "כל הכבוד אלוף!", "מדהים!!!", המון סימני קריאה |
| קצר, נושם, בעברית פשוטה | מוסדי — "עליך להשלים את המטלה", "נא לאשר קבלה" |
| מכיל, בלי לחץ | דוחק — "מהר!", "נשארו לך X שניות" |
| עברית מלאה | קיצורים באנגלית, סלנג מאולץ |

> **הבטחת הקול:** אפס משפטים שהיו נשמעים רע אם מחנכת אמיתית הייתה אומרת אותם לילד בזמן מלחמה. כל נוסח כאן עבר את המבחן הזה.

> **קו אדום (מ-`flags-protocol.md`):** נוסח שאומר לתלמיד "{{מחנך}} יראה את זה ויחזור אליך" מוצג **רק** כשהפרוטוקול באמת מבטיח פנייה אנושית (check-in של "קשה לי" / "רוצה לדבר"). המערכת לא מבטיחה בשם אדם דבר שלא יקרה. המערכת גם **לעולם לא** אומרת לתלמיד שהוא "אדום" או "בדגל" — היא רק אומרת שמישהו ראה אותו.

## 1. משתנים שמוזרקים בזמן ריצה

הנוסחים מכילים מצייני-מקום. הקוד ממלא אותם לפני התצוגה:

| ציין-מקום | מה זה | דוגמה |
|-----------|--------|--------|
| `{{שם}}` | שם פרטי של התלמיד | "יובל" |
| `{{מספר}}` | מספר ימי הרצף | "4" |
| `{{מחנך}}` | שם המחנך/ת להצגה | "דנה" |
| `{{ראה_מחנך}}` | פועל שמתאים למגדר **המחנך/ת** | ראה / ראתה |
| `{{יחזור_מחנך}}` | פועל שמתאים למגדר **המחנך/ת** | יחזור / תחזור |

```js
// פותר מגדר המחנך/ת. מגדר התלמיד מטופל דרך {m}/{f} בבנק עצמו.
function resolveEducatorVerbs(educatorGender /* "m" | "f" */) {
  return {
    "ראה_מחנך":   educatorGender === "f" ? "ראתה"  : "ראה",
    "יחזור_מחנך": educatorGender === "f" ? "תחזור" : "יחזור",
  };
}
```

> **מבנה מגדרי:** כל נוסח שנוגע לתלמיד כתוב ב-`{m: "", f: ""}` — `m` לפנייה לבן, `f` לפנייה לבת. אם המערכת לא יודעת מגדר — ברירת המחדל `m` (או ניסוח נייטרלי, כשקיים).

## 3. איך משתמשים (דוגמת שליפה)

```js
// בחירת נוסח לפי מגדר התלמיד + מילוי משתנים
function pick(entry, studentGender, vars) {
  let text = entry[studentGender] || entry.m;
  return text.replace(/\{\{(\w+)\}\}/g, (_, k) => vars[k] ?? "");
}

// דוגמה: תגובת "רוצה לדבר" לבת, שהמחנכת שלה היא "דנה"
const vars = { "שם": "מאיה", "מחנך": "דנה", ...resolveEducatorVerbs("f") };
pick(STUDENT_COPY.checkin.response.talk, "f", vars);
// → "טוב שפנית, מאיה. דנה ראתה שביקשת לדבר, ותחזור אלייך עוד היום. את לא צריכה לחכות עם זה לבד."

// גרסה מתחלפת של סיום משימה (מערך) — לפי אינדקס מסתובב
const i = completedCount % STUDENT_COPY.taskDone.length;
pick(STUDENT_COPY.taskDone[i], studentGender, vars);
```

## 4. הגדרת סיום — מבחן ה"מחנכת בזמן מלחמה"

עברתי נוסח-נוסח מול השאלה: *האם מחנכת אמיתית הייתה אומרת את זה לילד בזמן מלחמה?*

- ✅ **ברכות חירום** — רכות, בלי "מעולה!", בלי דחיפה. "אנחנו כאן", "אין למה למהר".
- ✅ **"קשה לי" / "רוצה לדבר"** — מכילים, אומרים במפורש מי ראה ומתי יחזור, ומדגישים "לא לבד". ה"היום" של "רוצה לדבר" תואם את סף הדחיפות ב-`flags-protocol.md`.
- ✅ **חזרה אחרי היעדרות** — אפס אשמה. "טוב לראות אותך", "לא צריך להסביר כלום". אין "איפה היית".
- ✅ **שגיאה** — "נתקע אצלנו, לא אצלך". בלי האשמת התלמיד, בלי קוד מפחיד.
- ✅ **רצף וסיום** — רגועים, אישיים, בלי תחרות ובלי חגיגה רועשת.

## 5. שאלות פתוחות למיטל

1. **מגדר המחנך/ת אוטומטי:** הנחתי ש-`StaffMember` יישא שדה מגדר כדי לפתור `ראה/ראתה`, `יחזור/תחזור`. כרגע `data-model.md` (§2.3) לא כולל מגדר לאיש צוות — לאשר הוספת שדה, או להשתמש בניסוח נייטרלי ("{{מחנך}} כבר ראה/ראתה") שפחות זורם.
2. **הדלת הנוספת ב"רוצה לדבר":** כתבתי "אתה לא צריך לחכות לבד" בלי מספר טלפון/כפתור חירום ישיר. האם להוסיף כפתור "התקשר עכשיו" (קו סיוע / מחנך) לצד ההודעה, או להשאיר את הפנייה אנושית בלבד דרך המחנך?
3. **וריאציית ברכות:** יש נוסח אחד לכל מצב×שעה. אם רוצים תחושת חיים — אפשר 2-3 נוסחים מתחלפים לכל תא (כמו סיום המשימה). לומר אם שווה להרחיב.
