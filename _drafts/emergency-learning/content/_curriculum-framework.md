# מסגרת רגולטורית — חינוך טכנולוגי-מקצועי לנוער (משרד העבודה)

**סטטוס:** מחקר-עוגן · **עודכן:** 16.7.2026 · **מקורות:** Perplexity → מרכז מחקר ומידע הכנסת, מבקר המדינה, זרוע העבודה (gov.il), מסמכי סל תוכניות תשפ"ז (ORT · פרטי).

> קובץ זה מעגן את `production-plan` במסגרת הרשמית. כל יחידת תוכן נגזרת ממנו + ממסמך המקור של המקצוע. **מקורות המאקרו (הכנסת/מבקר) מתארים מסגרת — הפירוט המודולרי נמצא במסמכי סל תוכניות תשפ"ז שבידינו.**

## 1. שתי מערכות נפרדות
| | משרד החינוך | **משרד העבודה (זרוע העבודה)** ⬅ אנחנו |
|---|---|---|
| בסיס חוקי | חוק חינוך חובה/ממלכתי | **חוק החניכות + חוק עבודת הנוער** |
| יעד תעודה | תעודת בגרות | **תעודת מקצוע** (+ צבירת יח"ל בגרות) |
| מודל | מגמות בתוך תיכון עיוני | בי"ס מקצועי · למידה דו-מערכתית (ביה"ס+עבודה) |
| היקף | ~90% מהטכנולוגי (~158K) | ~10% (~10K תלמידים) |
| גוף מפקח | — | **מינהל בכיר להכשרות מקצועיות ופיתוח כוח אדם** |

מקור: מ.מ.מ הכנסת (2014, 2018/19) · מבקר המדינה "הכשרה מקצועית לנוער". [מקור: כנסת/מבקר]

## 2. מבנה ההסמכה — ~14 ענפי הכשרה, ~70–80 מקצועות
מסלול נוער: **3–4 שנים** (בוגרי ח'), עיוני+מעשי, סיום בבחינות הסמכה עיוניות ומעשיות → **תעודת מקצוע**. [מקור: זרוע העבודה]

## 3. מדרג הכישורים הישראלי (NQF / תרגום EQF)
מסגרת לאומית ל-8 רמות. כל רמה מוגדרת ב-3 ממדים (מקור: `תרגום_מדרג_EQF.docx` · סל תוכניות תשפ"ז):

| ממד | מה זה |
|---|---|
| **ידע** | עובדות, עקרונות, תהליכים, מושגים |
| **מיומנויות** | קוגניטיביות + מעשיות — יישום, פתרון בעיות |
| **אחריות ואוטונומיה** | מידת הפיקוח/עצמאות בעבודה |

תעודת מקצוע לנוער ≈ **רמות 3–4** (הכשרה על-יסודית) — הערכה, לא קביעה רשמית.
**השלכה לתוכן:** 3 הרמות שלנו (`basic`/`standard`/`advanced`) מקבילות לעלייה בממד האחריות/אוטונומיה — לא רק "קל→קשה".

## 4. טקסונומיית "ספיינס" (Spines) — מבנה שיוך מגמה
מתוך `הערות פורמט.docx`. כל מקצוע משויך: **תחום → אשכול → קבוצה → מגמה → מקצוע**.
- **חתך ביקוש:** אדום / כתום / ירוק (אוטומטי לפי טבלת מגמות). אדום = ביקוש גבוה בשוק.
- כשירויות נכתבות במודל NQF (ידע/מיומנויות/אחריות) + **אופק תעסוקתי · אופק לימודים · סיכוני המקצוע** — בנקודות, לא פסקאות.
- הערה: לא מכשירים טכנאים/הנדסאים. עברית כשפת חובה (הבנת הנשמע/הנקרא/כתיבה) — בעיקר בחתכים אדומים.

## 5. לימודי ליבה (בסיס) לצד המקצוע
ליבת תעודת גמר טכנולוגית: **עברית · אנגלית · מתמטיקה** (חובה). ORT הרחיבה ל"תוכנית הלימודים היוצרת בלימודי הבסיס" (הומניסטיקה, אזרחות, היסטוריה, תנ"ך, ספרות, מדעי-סביבתי, בריאותי-גופני). היקף שעות מדויק — במסמכים הפנימיים, לא בסקירות המאקרו. [מקור: כנסת · סל תוכניות תשפ"ז]

**השלכה לרֶצֶף:** מקצועות הליבה ההומניסטיים/שפתיים = **אזור-סכנה** (טיר 4) — כל קביעה פדגוגית עוברת Perplexity + מקור סמכותי (אקדמיה ללשון / משרד החינוך) + `verify-pedagogy`. המגמות המקצועיות = טיר 2 (נגזר ממסמך המקור בלבד).
