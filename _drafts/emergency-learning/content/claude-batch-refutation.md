## 7 צירי הבדיקה (לכל יחידה באצווה)

**1. דיוק עובדתי — הכי חשוב.**
קביעה מקצועית שגויה / "בטוחה-אבל-שגויה" / הכללת-יתר מטעה → 🔴. כל קביעה שאינה נכונה חד-משמעית, גם אם "נשמעת סבירה".

**2. מבנה DNA.**
3 רמות (basic/standard/advanced)? סדר פתיח→הסבר→דוגמה→שאלות→סיכום? שאלות 2/3/3? מנה אחת? frontmatter מלא · `unit_type`=task/assessment (לא "ידע/מיומנות") · `pedagogy_verified: [לאימות]`?

**3. אורך ושפה.**
משפט >12 מילים? מסך >40? שפה מסובכת לקהל היעד? מונח לא מוסבר? → סמן.

**4. פנייה ניטרלית-מגדרית.**
ציווי בזכר יחיד ("לבש"/"שים"/"אתה") במקום לשון רבים סתמית ("לובשים"/"בודקים")? → סמן. חובה ניטרלי.

**5. דרך ההערכה.**
תואמת את סוג התוכן או נפלה ל"אמריקאית" כברירת-מחדל? מיומנות שנבחנת בחידון במקום בביצוע? שאלה בלי תשובה חד-משמעית, או מסיח שאינו באמת שגוי? → סמן. לכל פתוחה — מחוון.

**6. תיוג מקור + סטריאוטיפ-כחוק.**
קביעה בלי `[מקור: ...]`? נתון/תקן/שם שהומצא בלי בסיס → 🔴. קביעה מוחלטת / מוסכמה-כחוק ("X קובע הכול", "צבע=רגש") → סמן; דורש "עשוי/לרוב/בהתאם ל".

**7. תיוג סוגי-טעות (EPA).**
כל מסיח בשאלת-ידע מתויג `error_type` מתוך {concept · rule-application · form-confusion · overgeneralization · attention} + אוברליי-מקצוע (`error-types.md §3`)? מסיח שלא נופל באף קטגוריה = חלש → סמן לשכתוב. במיומנות: פריטי רשימת-התיוג (עבר/לא עבר) הם צירי-הטעות.

## שער ליבה (טיר 4/5) — verify-pedagogy חובה
לפני שמודולת-ליבה עוברת ל"חתימה":
1. כל קביעה פדגוגית (לשון/תנ"ך/היסטוריה/אזרחות) → **Perplexity → מקור סמכותי** (אקדמיה ללשון / משה"ח / מקרא+מפרשים).
2. הרץ את הסקיל `verify-pedagogy` על הקובץ.
3. שגיאה שנתפסה → תקן **וגם** עדכן את `llm-pitfalls.md` (שלא תחזור).
> verify-pedagogy מחליף כאן מומחה-תחום אנושי (החלטת מיטל) — אבל רק לליבה ההומנית. RED-בטיחות במגמות עדיין דורש ממונה בטיחות.

## אחרי הבדיקה — עדכון הלוח
- **נמצאו 🔴** → Claude מתקן במקום (יצרן לא נדרש שוב לתיקון נקודתי) → חוזר לבדיקה קצרה.
- **[כשיר לחתימה]** → העבר בלוח ל**"תיקון + חתימה"**. מגמה→רכז · ליבה→מעבר verify-pedagogy = החתימה.
- **נחתם** → Codex ממיר .md→JSON, מעדכן מניפסט → הלוח ל**"הומר"**.
- לא משכתבים יחידות שלמות — אבחון ותיקון נקודתי בלבד.
