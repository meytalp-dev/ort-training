## 0. העיקרון (מה שמבדיל העשרה מקוריקולום)

> **תוכנית לימוד = רצף הסברים** (חובה → אחידות, יעילות).
> **קורס העשרה = רצף חוויות** (בחירה → גיוון, "וואו").

קורס העשרה לא נראה כמו שיעור. התלמיד **עושה**, לא **קורא**. אותה פדגוגיה (מנה קצרה, רעיון מרכזי, מסלול הצלה) — אבל עטופה בחוויה שגורמת לבחור להיכנס.

**כלל התשתית לא נשבר:** אין נגן שני, אין מסד שני, אין ממשק תלמיד שני. סוגי-המסך הם **הרחבת אוצר-המילים** של אותו מנוע יחידות. הקוריקולום משתמש ב-3 סוגים; ההעשרה משתמשת בכל 7.

**למה זה אפשרי כאן ולא בקוריקולום:** ההעשרה היא **מעט קורסים (4)** — אז אפשר להשקיע עושר שאי אפשר על פני מאות יחידות חובה. 4 קורסים מושקעים > 60 יחידות משעממות.

## 1. סכימה — מסך הוא `screen` עם `type`

כל קורס = אוסף שיעורים. כל שיעור = מערך `screens[]`. כל מסך הוא אובייקט עם `type` שקובע איזו חוויה, ו-`data` לפי הסוג. זהו אותו מבנה של `demo-unit-hebrew.json`, מורחב.

```
LESSON = { id, title, kicker, facts[], screens: [ SCREEN, ... ] }
SCREEN = { type, ...data }     // type ∈ 7 הסוגים למטה
```

**מקרא:** 🎛️ פעולת התלמיד · 🗂️ מבנה נתונים · 🔒 מינימיזציה/פרטיות · 〰️ מתחבר לקו-הרצף.

## 2. שבעת סוגי-המסך

### 2.1 🔀 `scenario` — תרחיש: בחירה ← תוצאה  ✅ הוכח
- **מתי:** לפתוח נושא ברגש, להראות "מה קורה אם". החזק ביותר כפתיחה.
- 🎛️ בוחר אחת מ-2–3 אפשרויות → נחשפת תוצאה (מנצחת / פחות טובה) עם הסבר קצר.
- 🗂️ `{ type:'scenario', q, choices:[{label, sub, icon, result}], results:{key:{tone, title, text}} }`
- **דגש:** אין "טעות מביישת" — כל בחירה מלמדת. התוצאה היא התובנה, לא ציון.

### 2.2 📄 `artifact` — חפץ לעבודה  ✅ הוכח
- **מתי:** כשיש חפץ אמיתי לתפעל — דף חשבון, פוסט לניתוח, מודעה, קורות-חיים.
- 🎛️ מגייד/מסמן/מסדר את החפץ בעצמו; סיכום חי מתעדכן (tally).
- 🗂️ `{ type:'artifact', header, note, rows:[{desc,sub,amt}], cats:[...], tally:true }`
- 🔒 **חפצים פיקטיביים בלבד** (בנק "אופק לצעירים", לא בנק אמיתי) — כמו `feedback-finansklass-lesson-standards`. לסמן "(דוגמה)".

### 2.3 🎛️ `simulator` — סימולטור: הזז ← ראה בזמן אמת  ✅ הוכח
- **מתי:** כשיש יחסים/פרופורציות שכדאי להרגיש — תקציב, ריבית לאורך זמן, "טמפרטורת" פרומפט.
- 🎛️ גורר מחוונים / משנה קלט → פס/מספר/גרף מגיב מיידית + פידבק מילולי (ירוק/אזהרה).
- 🗂️ `{ type:'simulator', total, controls:[{key,label,min,max,step,init,color}], feedbackRules:[...] }`

### 2.4 ⚖️ `decide` — השווה והחלט  ✅ הוכח
- **מתי:** כשיש כמה דרכים לגיטימיות ואין אחת נכונה — שיטות תקציב, כלי AI, מבני דף מכירה.
- 🎛️ קורא 2–3 אופציות, לכל אחת יתרונות/חסרונות + **"למי זה מתאים"**, ובוחר את שלו.
- 🗂️ `{ type:'decide', q, options:[{title,sub,icon,body,pros[],cons[],fit}] }`
- **דגש (מ-`finansklass-standards` §8):** לכל אופציה הסבר מלא + 2 יתרונות + 2 חסרונות + "למי זה מתאים". לא "יתרון אחד וחיסרון אחד".

### 2.5 🚀 `mission` — משימה בעולם האמיתי  ✅ הוכח
- **מתי:** לסגור שיעור — להפוך ידע להרגל. תמיד לצד `remember` (מה לזכור).
- 🎛️ מקבל משימה קונקרטית לשבוע: **מה עושים · איפה רושמים · כמה זמן** (מ-`finansklass-standards` §5).
- 🗂️ `{ type:'mission', title, steps[], when, remember }`
- 〰️ סימון "סיימתי" מקדם ברצף הקורס.

### 2.6 🤖 `ai-hands` — AI בידיים  🟡 להוסיף
- **מתי:** קורס ה-AI, ובכל מקום שכלי AI חיצוני הוא הפעילות.
- 🎛️ הנחיה מודרכת (3–4 צעדים "איך נכנסים", ברירת מחדל **ג'מיני** דרך חשבון בי"ס — `finansklass-standards` §3) → התלמיד עובד **בחשבון שלו** → מדביק/מדווח מה קיבל. אזור השוואה "פרומפט חלש מול חזק".
- 🗂️ `{ type:'ai-hands', tool, login[], task, promptStarter, reflect }`
- 🔒 **קו אדום נשמר:** המערכת **לא** שולחת נתוני תלמיד למודל חיצוני (W8-03, `security-minimization.md`). התלמיד מפעיל בעצמו; רֶצֶף רק מנחה ואוסף רפלקציה מקומית. זה מה שהפך את קורס-AI ל"תוכן סטטי בלבד" ב-`course-integration.md` §3 — סוג-המסך הזה הוא הפתרון התואם-מינימיזציה.

### 2.7 🖼️ `gallery` — גלריית השראה / לפני-אחרי  🟡 להוסיף
- **מתי:** עיצוב, צילום, יזמות — כשצריך לגרום **לרצות** לפני שמלמדים איך.
- 🎛️ מדפדף בדוגמאות / מחליק מחוון "לפני↔אחרי" / בוחר "מה עובד פה".
- 🗂️ `{ type:'gallery', items:[{before,after,caption,why}] , mode:'slider'|'grid' }`

**מסך עזר (לא-סוג):** `hook` — וו פתיחה (hero + "למה זה שלך"). פותח כל שיעור, בלי אינטראקציה. `explain` הקלאסי עדיין זמין לרגעי הסבר קצרים בין חוויות — אבל לא כשלד השיעור.

## 3. כלל ההרכבה — איך בונים שיעור

1. **פותחים ב-`hook`** (וו) — סקרנות, לא כותרת.
2. **1–2 חוויות ליבה** מהסוגים 🔀/📄/🎛️/⚖️/🤖/🖼️ — לפי הנושא.
3. **סוגרים ב-`mission` + `remember`** — הרגל + רעיון מרכזי.
4. **אורך:** 4–6 מסכים לשיעור. משך גמיש (`prd.md` §5), בלי "10 דקות" קבוע.
5. **גיוון בתוך קורס:** לא לחזור על אותו סוג-מסך שיעור אחרי שיעור. תרחיש הפעם, חפץ בפעם הבאה.
6. **נגישות:** כל אינטראקציה נשענת על טקסט+אייקון, לא צבע בלבד (`a11y-checklist.md`).

| **כסף חכם** | פיננסים | **ייבוא** מפיננסקלאס | ~5 | 🔀 · 📄 חפץ · 🎛️ סימולטור · ⚖️ | 1 |
| **עוזר AI לחיים ולעבודה** | AI | **ייבוא סטטי** + 🤖 | ~5 | 🤖 AI-בידיים · 🔀 · ⚖️ | 2 |
