## 0. מה המסמך הזה, ולמי

המחנך רואה בלוח הדופק (`educator-pulse.html`) ילד שלא נראה — צהוב, אדום, או דגל רגשי — ולוחץ **"שלח וואטסאפ"**. הכפתור פותח את הוואטסאפ שלו עם **הודעה מוכנה** לילד. זה בנק ההודעות האלה.

הבנק הזה מחליף את הנוסחים ה-inline שיש היום ב-`educator-pulse.html` (`waMessage`) ומרחיב אותם למצבים נוספים.

### הכלל היחיד שממנו הכול נגזר

> **ההודעה חייבת להיראות כאילו יצאה מהטלפון של אדם — לא מבוט ולא מהתראה מוסדית.**

בן 16 במלחמה מזהה הודעת-מערכת בשנייה, ומתעלם. הודעה שנשמעת כמו מחנך אמיתי ששלח לו — הוא עונה. **המבחן של כל שורה כאן:** האם בן 16 היה עונה לה, או גולל הלאה?

### הקול — מה כן, מה לא

| כן | לא |
|-----|-----|
| גוף ראשון — "רק רציתי לראות", "חשבתי עליך" | "המערכת שמה לב", "זוהתה היעדרות" |
| קליל, אישי, בגובה העיניים | מוסדי — "נא ליצור קשר", "עליך לעדכן" |
| דואג בלי להלחיץ | מלחיץ — "למה לא נכנסת?!", "חובה להשלים" |
| דלת פתוחה, בלי דרישה | אשמה — "איפה היית?", "אתה מפספס חומר" |
| משפט-שניים, אורך של וואטסאפ | פסקה, מכתב, טופס |

### שני קווים אדומים

1. **בפנייה אחרי דגל "קשה לי" — לעולם לא לחשוף שהמערכת "הלשינה".** אסור "ראיתי שסימנת שקשה לך" או "המערכת התריעה עליך". פונים בחום אנושי כאילו סתם חשבת עליו. הילד כבר יודע שמישהו יראה ויחזור אליו (`copy-student.md` §2) — אבל ההודעה עצמה מרגישה אישית, לא מנוטרת.
2. **המחנך עורך לפני שליחה.** כל נוסח כאן הוא **טיוטה בקולו של המחנך** — הוא משנה מילה, מוסיף בדיחה פנימית, חותם בשמו. זה בדיוק העיקרון מ-`flags-protocol.md`: "המערכת פותחת הודעה מוכנה — תערוך אותה שתישמע ממך". לכן פעלים בגוף ראשון של השולח נכתבו בזמן עבר (ניטרלי מגדרית: "רציתי", "שמתי לב", "שמחתי") כדי שיתאימו למחנך ולמחנכת כאחד ללא עריכה.

## 1. איך זה עובד עם המגדר

- **משתנה יחיד:** `[שם]` — השם הפרטי של התלמיד. הקוד ממלא אותו לפני הפתיחה של הוואטסאפ.
- **שני מגדרים `{m, f}`** — מתייחסים ל**מגדר התלמיד** (הנמען): `m` לפנייה לבן, `f` לפנייה לבת. אם המגדר לא ידוע — ברירת מחדל `m`.
- בהודעה **להורה**, ה-`{m,f}` הוא מגדר **הילד** ("לא נכנס / לא נכנסה").
- ב**הודעה הכיתתית** אין `[שם]` ואין מגדר יחיד — היא נשלחת לכל הכיתה בלשון רבים; שני המפתחות `{m,f}` נושאים את אותו נוסח (רבים), נשמר לעקביות מבנית בלבד.

## 3. איך משתמשים (דוגמת שליפה)

```js
// בחירת נוסח לפי מגדר התלמיד + מילוי [שם]
function pickOutreach(entry, studentGender, name) {
  const text = entry[studentGender] || entry.m;
  return text.replace(/\[שם\]/g, name);
}

// דוגמה: יום שקט, נוסח מתחלף לפי היום, לבת בשם "מאיה"
const list = OUTREACH_TEMPLATES.quietDay;
const i = dayIndex % list.length;   // מסתובב כדי שלא תמיד אותו נוסח
pickOutreach(list[i], "f", "מאיה");
// → "היי מאיה, מה קורה? לא ראיתי שנכנסת היום — הכול טוב אצלך? בטח פשוט יום עמוס."

// בונים קישור וואטסאפ (פורמט api.whatsapp.com, לא wa.me)
function waLink(phone, text) {
  return "https://api.whatsapp.com/send?phone=" + phone +
         "&text=" + encodeURIComponent(text);
}
```

> **בחירת התבנית לפי מצב הילד בלוח הדופק:** לא נראה היום → `quietDay` · לא נראה 2–3 ימים → `fewDays` · דגל "קשה לי" → `afterHardFlag` · חזר אחרי היעדרות → `afterReturn`. `toParent` נפתח רק מהמסלול של "אין מענה מהילד" (spec §5.7, `flags-protocol` חלק ב׳). `classDaily` הוא כפתור נפרד "הודעה לכיתה", לא פנייה אישית.

## 4. בדיקה עצמית — "בן 16 במלחמה: עונה או מתעלם?"

עברתי תבנית-תבנית מול השאלה. מחקתי כל מה שנשמע כמו מערכת.

| # | קטגוריה | למה בן 16 יענה, ולא יתעלם |
|---|----------|----------------------------|
| 1 | יום שקט | "סתם רציתי לראות" — בלי דרמה, בלי חובה. מרגיש כמו הודעה מאדם, לא נדנוד. |
| 2 | יומיים-שלושה | דואג אבל לא מאשים. "רק רציתי לוודא שאתה בסדר" ולא "למה נעלמת". דלת, לא חקירה. |
| 3 | אחרי "קשה לי" | **אפס חשיפה של המערכת.** "חשבתי עליך" — הוא לא מרגיש מנוטר או ש"הלשינו" עליו. חום + דלת פתוחה, בלי אבחון. |
| 4 | חזרה אחרי היעדרות | "טוב שחזרת", "לא צריך להסביר כלום". אין "איפה היית", אין "תשלים". אפס אשמה = הוא ייכנס שוב מחר. |
| 5 | להורה | עדכון שותפות ("רצינו לבדוק שהכול בסדר"), לא תלונה. ההורה לא נכנס למגננה — ולכן עוזר. |
| 6 | כיתתית | לשון רבים חמה, "חושבים עליכם", דרישה מינימלית ("רק שנדע שאתם שם"). מרגיש כמו מחנך שאכפת לו, לא כמו רשימת נוכחות. |

**מה נמחק בדרך (דוגמאות למה שלא נכנס):**
- ✗ "זוהתה היעדרות של יומיים במערכת" — מוסדי, מרתיע.
- ✗ "ראיתי שסימנת שקשה לך" — חושף את הצ'ק-אין, מרגיש כמו מעקב (קו אדום §0).
- ✗ "עליך להשלים 3 משימות שהצטברו" — דרישה + אשמה. הילד סוגר את הצ'אט.
- ✗ "איפה היית כל השבוע?" — האשמה. הכי בטוח לגרום לו לא לחזור.

**הגדרת הסיום מתקיימת:** 14 תבניות (3+3+2+2+2+2), כל אחת `[שם]` + `{m,f}` + עד 2 משפטים, כולן בנוסח שמחנכת אמיתית הייתה שולחת כמו-שהן (אחרי עריכה קלה בקולה).

## 5. שאלות פתוחות למיטל

1. **מגדר המחנך/ת בהודעה להורה.** כתבתי "המחנך/ת של [שם]" עם לוכסן, כי אין ל-`StaffMember` שדה מגדר (זהה לפתוח של `copy-student.md` §5.1 / T1.3). אם יתווסף שדה מגדר לצוות — אפשר לפתור אוטומטית ("המחנך של" / "המחנכת של"). כרגע המחנך עורך את הלוכסן ביד לפני שליחה.
2. **חתימה בשם המחנך.** לא הוספתי `[מחנך]` בסוף ההודעות — הנחתי שהמחנך שולח מהטלפון האישי שלו, ולכן הילד/ההורה כבר רואה מי שלח. אם רוצים חתימה מפורשת ("— דנה, המחנכת") אפשר להוסיף שדה. לאשר.
3. **וריאציה של הודעה כיתתית לפי מצב.** יש 2 נוסחים כלליים. האם להרחיב לנוסח נפרד למצב חירום (רך יותר) מול שגרה (יומיומי), כמו שעשינו בברכות התלמיד?
4. **"התקשר עכשיו" בדגל רגשי.** תואם לשאלה הפתוחה ב-`copy-student.md` §5.2 — האם לצד תבנית `afterHardFlag` להציע גם כפתור חיוג ישיר, או להשאיר וואטסאפ בלבד.
