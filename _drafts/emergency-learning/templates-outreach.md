**גרסה:** 1.1 · **תאריך:** 9.7.2026 · **סטטוס:** הכרעות מיטל יושמו (חתימת מחנך · הודעה כיתתית לפי מצב · ניסוח נייטרלי לצוות · פנייה אנושית בלבד)

## 0. מה המסמך הזה, ולמי

המחנך רואה בלוח הדופק (`educator-pulse.html`) ילד שלא נראה — צהוב, אדום, או דגל רגשי — ולוחץ **"שלח וואטסאפ"**. הכפתור פותח את הוואטסאפ שלו עם **הודעה מוכנה** לילד. זה בנק ההודעות האלה.

הבנק הזה מחליף את הנוסחים ה-inline שיש היום ב-`educator-pulse.html` (`waMessage`) ומרחיב אותם למצבים נוספים.

### הכלל היחיד שממנו הכול נגזר

> **ההודעה חייבת להיראות כאילו יצאה מהטלפון של אדם — לא מבוט ולא מהתראה מוסדית.**

בן 16 במלחמה מזהה הודעת-מערכת בשנייה, ומתעלם. הודעה שנשמעת כמו מחנך אמיתי ששלח לו — הוא עונה. **המבחן של כל שורה כאן:** האם בן 16 היה עונה לה, או גולל הלאה?

### הקול — מה כן, מה לא

| כן | לא |
|-----|-----|
| גוף ראשון — "רק רציתי לראות", "חשבתי עליך" | "המערכת שמה לב", "זוהתה היעדרות" |
| קליל, אישי, בגובה העיניים | מוסדי — "נא ליצור קשר", "עליך לעדכן" |
| דואג בלי להלחיץ | מלחיץ — "למה לא נכנסת?!", "חובה להשלים" |
| דלת פתוחה, בלי דרישה | אשמה — "איפה היית?", "אתה מפספס חומר" |
| משפט-שניים, אורך של וואטסאפ | פסקה, מכתב, טופס |

### שני קווים אדומים

1. **בפנייה אחרי דגל "קשה לי" — לעולם לא לחשוף שהמערכת "הלשינה".** אסור "ראיתי שסימנת שקשה לך" או "המערכת התריעה עליך". פונים בחום אנושי כאילו סתם חשבת עליו. הילד כבר יודע שמישהו יראה ויחזור אליו (`copy-student.md` §2) — אבל ההודעה עצמה מרגישה אישית, לא מנוטרת.
2. **המחנך עורך לפני שליחה.** כל נוסח כאן הוא **טיוטה בקולו של המחנך** — הוא משנה מילה, מוסיף בדיחה פנימית, חותם בשמו. זה בדיוק העיקרון מ-`flags-protocol.md`: "המערכת פותחת הודעה מוכנה — תערוך אותה שתישמע ממך". לכן פעלים בגוף ראשון של השולח נכתבו בזמן עבר (ניטרלי מגדרית: "רציתי", "שמתי לב", "שמחתי") כדי שיתאימו למחנך ולמחנכת כאחד ללא עריכה.

## 1. איך זה עובד עם המגדר

- **משתנה יחיד:** `[שם]` — השם הפרטי של התלמיד. הקוד ממלא אותו לפני הפתיחה של הוואטסאפ.
- **שני מגדרים `{m, f}`** — מתייחסים ל**מגדר התלמיד** (הנמען): `m` לפנייה לבן, `f` לפנייה לבת. אם המגדר לא ידוע — ברירת מחדל `m`.
- בהודעה **להורה**, ה-`{m,f}` הוא מגדר **הילד** ("לא נכנס / לא נכנסה").
- ב**הודעה הכיתתית** אין `[שם]` ואין מגדר יחיד — היא נשלחת לכל הכיתה בלשון רבים; שני המפתחות `{m,f}` נושאים את אותו נוסח (רבים), נשמר לעקביות מבנית בלבד. ההודעה הכיתתית מפוצלת לפי **מצב** (`routine` / `remote` / `emergency`) — ראו §2 קטגוריה 6.
- **מגדר המחנך/השולח — נייטרלי תמיד.** אין שדה מגדר לצוות (`StaffMember`), וגם לא נוסיף. כל נוסח שנכתב בקול השולח מנוסח נייטרלית: פעלים בזמן עבר בגוף ראשון ("רציתי", "שמתי לב"), לשון רבים ("אנחנו כאן"), או צורה משולבת ("המחנך/ת"). כך אותה תבנית מתאימה למחנך ולמחנכת ללא עריכה.
- **חתימה בשם המחנך (רשות):** אפשר לצרף לתחתית ההודעה חתימה בשם המחנך דרך הפרמטר `educatorName` ב-`pickOutreach` (ראו §3). החתימה היא **שם בלבד** ("— דנה") — נייטרלית מגדרית מעצם היותה שם. אם לא מועבר שם — לא מתווספת חתימה, וההודעה נשלחת מהטלפון האישי כרגיל.

## 3. איך משתמשים (דוגמת שליפה)

```js
// בחירת נוסח לפי מגדר התלמיד + מילוי [שם] + חתימה נבחרת בשם המחנך
// educatorName — רשות. אם מועבר, מתווסף בתחתית ההודעה כחתימה ("— דנה").
function pickOutreach(entry, studentGender, name, educatorName) {
  let text = entry[studentGender] || entry.m;
  text = text.replace(/\[שם\]/g, name);
  if (educatorName) {
    text += "\n\n— " + educatorName;   // חתימה נייטרלית: שם בלבד
  }
  return text;
}

// דוגמה: יום שקט, נוסח מתחלף לפי היום, לבת בשם "מאיה", בחתימת "דנה"
const list = OUTREACH_TEMPLATES.quietDay;
const i = dayIndex % list.length;   // מסתובב כדי שלא תמיד אותו נוסח
pickOutreach(list[i], "f", "מאיה", "דנה");
// → "היי מאיה, מה קורה? לא ראיתי שנכנסת היום — הכול טוב אצלך? בטח פשוט יום עמוס.\n\n— דנה"
// (בלי הפרמטר הרביעי — אותו נוסח בלי חתימה)

// הודעה כיתתית לפי מצב: routine (שגרה) / remote (מרחוק) / emergency (חירום).
// אין [שם] ואין חתימה אישית בהכרח — אפשר לצרף educatorName גם כאן אם רוצים.
const mode = "emergency";           // נקבע לפי מצב המערכת בלוח הדופק
const classList = OUTREACH_TEMPLATES.classDaily[mode];
const j = dayIndex % classList.length;
pickOutreach(classList[j], "m", "", "דנה");

// בונים קישור וואטסאפ (פורמט api.whatsapp.com, לא wa.me)
function waLink(phone, text) {
  return "https://api.whatsapp.com/send?phone=" + phone +
         "&text=" + encodeURIComponent(text);
}
```

> **בחירת התבנית לפי מצב הילד בלוח הדופק:** לא נראה היום → `quietDay` · לא נראה 2–3 ימים → `fewDays` · דגל "קשה לי" → `afterHardFlag` · חזר אחרי היעדרות → `afterReturn`. `toParent` נפתח רק מהמסלול של "אין מענה מהילד" (spec §5.7, `flags-protocol` חלק ב׳). `classDaily` הוא כפתור נפרד "הודעה לכיתה", לא פנייה אישית — ונבחר בו נוסח לפי מצב המערכת (`routine` / `remote` / `emergency`).

> **הפנייה אנושית בלבד.** גם בדגל רגשי (`afterHardFlag`) הכפתור פותח וואטסאפ בקול המחנך — אין כפתור "התקשר עכשיו" ואין אוטומציית חיוג. המחנך הוא זה שיוצר קשר, מתי ואיך שנכון לו.

| 3 | אחרי "קשה לי" | **אפס חשיפה של המערכת.** "חשבתי עליך" — הוא לא מרגיש מנוטר או ש"הלשינו" עליו. חום + דלת פתוחה, בלי אבחון. |
| 4 | חזרה אחרי היעדרות | "טוב שחזרת", "לא צריך להסביר כלום". אין "איפה היית", אין "תשלים". אפס אשמה = הוא ייכנס שוב מחר. |
| 5 | להורה | עדכון שותפות ("רצינו לבדוק שהכול בסדר"), לא תלונה. ההורה לא נכנס למגננה — ולכן עוזר. |
| 6 | כיתתית | לשון רבים חמה, "חושבים עליכם", דרישה מינימלית ("רק שנדע שאתם שם"). מותאם למצב: שגרה יומיומית, מרחוק מחבר, חירום מרגיע. מרגיש כמו מחנך שאכפת לו, לא כמו רשימת נוכחות. |

**מה נמחק בדרך (דוגמאות למה שלא נכנס):**
- ✗ "זוהתה היעדרות של יומיים במערכת" — מוסדי, מרתיע.
- ✗ "ראיתי שסימנת שקשה לך" — חושף את הצ'ק-אין, מרגיש כמו מעקב (קו אדום §0).
- ✗ "עליך להשלים 3 משימות שהצטברו" — דרישה + אשמה. הילד סוגר את הצ'אט.
- ✗ "איפה היית כל השבוע?" — האשמה. הכי בטוח לגרום לו לא לחזור.

**הגדרת הסיום מתקיימת:** 18 תבניות (3+3+2+2+2+6 — הכיתתית 2 נוסחים × 3 מצבים), כל אחת `[שם]` + `{m,f}` + עד 2 משפטים, כולן בנוסח שמחנכת אמיתית הייתה שולחת כמו-שהן (אחרי עריכה קלה בקולה). חתימה בשם המחנך אופציונלית (`educatorName`), וקול השולח נייטרלי מגדרית.

## 5. הכרעות מיטל (סגור)

1. **מגדר המחנך/ת בהודעה להורה — ✓ הוכרע — ניסוח נייטרלי, בלי שדה מגדר לצוות.** לא מוסיפים שדה מגדר ל-`StaffMember`. כל נוסח בקול השולח מנוסח נייטרלית: "המחנך/ת של [שם]" (צורה משולבת), פעלים בגוף ראשון בעבר, ולשון רבים. אין תלות בעריכה ידנית של המגדר.
2. **חתימה בשם המחנך — ✓ הוכרע — להוסיף (רשות).** נוסף הפרמטר `educatorName` ל-`pickOutreach`; אם מועבר, מתווספת חתימה בשם המחנך בתחתית ההודעה ("— דנה"). החתימה היא שם בלבד ולכן נייטרלית מגדרית. בלי הפרמטר — ההודעה נשלחת מהטלפון האישי בלי חתימה מפורשת (§1, §3).
3. **וריאציה של הודעה כיתתית לפי מצב — ✓ הוכרע — לפצל ל-3 מצבים.** `classDaily` פוצל ל-`routine` (שגרה — קליל ויומיומי), `remote` (מרחוק — מחבר ומעודכן) ו-`emergency` (חירום — חם, מרגיע, נוכח), 2 נוסחים בכל מצב (§2 קטגוריה 6, §3).
4. **"התקשר עכשיו" בדגל רגשי — ✓ הוכרע — פנייה אנושית בלבד, בלי כפתור חיוג אוטומטי.** גם ב-`afterHardFlag` הכפתור פותח וואטסאפ בקול המחנך בלבד. אין כפתור "התקשר עכשיו" ואין אוטומציית חיוג — המחנך יוצר קשר בעצמו, מתי ואיך שנכון לו.
