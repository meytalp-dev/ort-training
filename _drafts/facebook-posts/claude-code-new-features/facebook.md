**● Auto Mode — בלי ללחוץ "אשר" כל 3 שניות**
עד עכשיו, כל פעולה שקלוד רצה לבצע דרשה אישור ידני. עכשיו יש מצב אוטומטי — קלוד מקבל החלטות בעצמו, עם מודל אבטחה נפרד שסורק כל פעולה לפני שהיא רצה.
התוצאה ← שיחה חלקה, בלי עצירות מיותרות.

**● Auto Dream — הזיכרון מתארגן בזמן שאת לא שם**
קלוד "חולם" בין שיחות — עובר על קבצי הזיכרון, מנקה מה שכבר לא רלוונטי, מאחד כפילויות, ומסדר הכל לקבצים נקיים לפי נושא. בדיוק כמו שהמוח שלנו מארגן מידע בזמן שינה.
התוצאה ← קלוד זוכר טוב יותר מה עשיתם ביחד, ולא שואל את אותן שאלות פעמיים.

**● Computer Use — קלוד שולט במחשב. פיזית.**
לא רק כותב קוד. קלוד עכשיו יכול לראות את המסך שלך, להזיז את העכבר, ללחוץ, להקליד, ולתפעל אפליקציות אמיתיות. כשאין לו כלי מתאים — הוא פשוט עובד כמו בן אדם.
התוצאה ← אפשר לבקש ממנו לעשות דברים שדרשו עד עכשיו עבודה ידנית מלאה.
