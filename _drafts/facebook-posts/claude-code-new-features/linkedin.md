# פוסט לינקדין — פיצ'רים חדשים Claude Code מרץ 2026

קלוד קוד השתדרג החודש בצורה משמעותית. שלושה פיצ'רים שמשנים את אופן העבודה:

● Auto Mode — קלוד מקבל החלטות הרשאה בעצמו, עם מודל אבטחה שסורק כל פעולה. בלי ללחוץ "אשר" עשרות פעמים בשיחה.

● Auto Dream — בין שיחות, קלוד עובר על הזיכרון שלו, מנקה מידע מיושן, מאחד כפילויות ומסדר הכל. כמו ארגון זיכרון בזמן שינת REM.

● Computer Use — קלוד רואה את המסך, מזיז עכבר, לוחץ ומקליד. כשאין כלי מתאים — הוא פשוט עובד על המחשב כמו בן אדם.
