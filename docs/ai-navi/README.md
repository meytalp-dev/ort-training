# AI NAVI — איך בוחרים את כלי הבינה הנכון למשימה הנכונה

מוצר דיגיטלי לוובינר בן 60 דקות + כלי ניווט אישי לבחירת כלי AI לפי המשימה.
סטטי לחלוטין — HTML/CSS/JS בלבד, בלי build, בלי שרת, בלי התחברות. עובד גם מ־`file://` וגם ב־GitHub Pages.

## הפעלה

פשוט לפתוח בדפדפן:

| קובץ | מה זה |

## קיצורי מקלדת במצגת

| מקש | פעולה |
|---|---|
| `←` / רווח / קליק על הרקע | קדימה (קודם חושף שלבי-חשיפה בשקופית) |
| `→` | אחורה |
| `A` | חשיפת תשובה במשחק/הצבעה |
| `N` | מגירת הערות מנחה (כולל טיימר וזמן-יעד לשקופית) |
| `G` | רשת קפיצה לשקופית (שקופיות משחק מסומנות) |
| `F` | מסך מלא |
| `D` | פתיחת הנווט בכרטיסייה חדשה (להדגמה החיה) |
| `R` | איפוס הצבעות בשקופית הנוכחית |
| `Shift+R` | איפוס כל ההצבעות |
| `Home` / `End` | שקופית ראשונה / אחרונה |

ההצבעות נשמרות מקומית בדפדפן (localStorage) — לאפס לפני וובינר חדש.

## עריכת תוכן — בלי לגעת בקוד

כל התוכן הדינמי בקובצי `data/`:

- **`data/tools.js`** — מאגר הכלים (23 כלים). להוסיף/לעדכן כלי = להוסיף אובייקט. שדה `lastReviewed` מציין מתי נבדק. אין שם מחירים מדויקים — בכוונה.
- **`data/families.js`** — 9 משפחות הכלים (קווי המטרו), כולל "מתאימה במיוחד / פחות מתאימה".
- **`data/routes.js`** — 12 המסלולים המוכנים: קלט, שלבים (מה ה-AI עושה / מה האדם עושה / מה לבדוק), אזהרות, פרומפט, 3 חלופות.
- **`data/slides.js`** — הערות מנחה, זמן-יעד לכל שקופית, וסדר השקופיות.

טקסטים של שקופיות עצמן — ב־`presentation.html` (כל שקופית = `<section>` מסומן בהערה).

## מנוע ההמלצות

`js/engine.js` — rules engine בלי AI:
1. בוחר מסלול מתוך `routes.js` לפי התאמת משימה+חומר גלם+תוצר (ציון ≥ 6; אחרת מסלול גנרי של כלי-אחד+בדיקה).
2. לכל שלב במסלול בוחר כלי לפי `roles` + ניקוד: התאמת משימה/קלט/פלט, סדרי עדיפויות, ניסיון מול קושי, זמן, מחיר, פרטיות, עברית. כולל חלופה לכל שלב.
3. מרכיב אזהרות לפי הקשר (מידע רגיש, מקורות, עיצוב-מול-דיוק, כלים חלשים בעברית) ופרומפט פתיחה.

## נגישות

RTL מלא, ניווט מקלדת, `aria-pressed`/`aria-live`/`role=status`, focus-visible, `prefers-reduced-motion`, כפתורים ≥48px, ניגודיות על רקע שמנת, הדפסת תוצאה (`@media print`) לשמירה כ-PDF.

## עיצוב
