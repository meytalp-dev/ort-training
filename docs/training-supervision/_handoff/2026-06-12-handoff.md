### 6. Phase 1 Hardening (Apps Script — לא דרוס)
**טאבים חדשים בסכמה:** `users`, `subjects`, `audit_log`
**Endpoints חדשים (5):**
1. `seed.import` — upsert JSON ל-Sheet (admin only)
2. `guide.dashboard` — כל המידע למדריכ/ה במסך אחד
3. `school.dashboard` — כל המידע למנהל ב"ס/רכז במסך אחד
4. `network.dashboard` — סטטיסטיקות שנתיות לרשת
5. `ministry.dashboard` — פילוח רשתות + בתי ספר חלשים

**Auth & Scope:**
- `requireAuthAndScope()` נקרא מ-handleRequest על כל פעולה
- `enforceScope_()` אוכף scope פר תפקיד
- ADMIN_ONLY: `seed.import`, `alerts.compute`, `certificate.generate`
- PUBLIC: `qr.checkin`, `qr.training`
- Backward compat: אם `users` ריק → bootstrap mode (לא שובר פיילוטים)

**Server-side cache:**
- `CacheService.getScriptCache()` + chunking >90KB
- TTL: guide=8דק' · school=8דק' · network=12דק' · ministry=20דק'
- cache key כולל scope → איזולציה בין משתמשים

**Audit log:**
- כל קריאה ל-endpoint נרשמת ל-`audit_log`

**Subjects migration:**
- `migrateSubjects()` helper — מפעילה ידנית מהעורך

## 🚧 בעיות פתוחות + צעדים הבאים

### 🔴 חוסם — מיטל צריכה לעדכן Apps Script
הקוד ב-Apps Script הוא **גרסה ישנה**. צריך לעדכן עם הקוד החדש מ-[code.gs Raw](https://raw.githubusercontent.com/meytalp-dev/ort-training/main/docs/training-supervision/apps-script/code.gs):
1. עורך Apps Script → Ctrl+A → Ctrl+V מהריפו
2. **ריצה אחת של `setupSchema`** — יוצר טאבים `users`/`subjects`/`audit_log` ומכניס את מיטל כ-`ministry_admin` ראשי
3. Deploy → Manage Deployments → ✏️ → New version → Deploy

### 🟡 דורש פעולה אחרי עדכון Apps Script
1. **טעינה חוזרת של נתוני שירה** — pilot-shira.html → "טעון נתוני פיילוט". seed.import הוא upsert, יוסיף את החסרים. **המהירות שופרה 5-10× עם setValues batch.**
2. **טעינת דמו 5 מקצועות** — אופציונלי, אם רוצים לראות איך נראים דשבורדים עם מספר מקצועות
3. **migrateSubjects()** — ריצה ידנית מעורך Apps Script לאחר טעינה

### 🔵 עיצוב — צריך להחיל "מצפן הפיקוח" על שאר הדשבורדים
**הושלם:** index.html · ministry/
**לא הושלם:**
- `admin-network/` — צריך page-header + command-strip + network-lens עבור ביה"ס
- `admin-school/` — צריך page-header + רכיב מצפן + טבלת המורים מעוצבת
- `guide/` — צריך page-header + עיצוב חדש לטבלת המורים שלי
- `checkin/` — צריך התאמה לפלטה החדשה (כרגע יש pastels)
- `teacher/` — לא הוטמע כלל

### 🟢 שיפורים עתידיים שעלו אבל לא הוטמעו
- "Execute as User accessing" ב-Apps Script (במקום "Execute as Me") — נדרש לפני שמפעילים auth מלא
- הוספת משתמשים אמיתיים לטאב `users` (כרגע במצב bootstrap)
- UI ל-feedback/alerts/heatmap (backend מוכן)
- לוגו רשמי של משרד העבודה (ממתין)
- העברה ל-domain ייעודי
