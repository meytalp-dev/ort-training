# תרגול מבחני גמר — מדריך הקמה

מערכת תרגול מבחני גמר של משרד העבודה, למגזר כללי ולמגזר ערבי, בכל המקצועות.

## מה יש במערכת

- **index.html** — דף כניסה: תלמיד / מורה
- **student.html** — לתלמיד: התחברות, בחירת מבחן, פתרון, הגשה
- **teacher.html** — למורה: דשבורד ציונים, בדיקת שאלות פתוחות, עריכת מחוונים, ייצוא CSV
- **exams/index.json** — קטלוג כל המבחנים
- **exams/<exam-id>.json** — שאלות כל מבחן
- **practice-exams-apps-script.js** — Backend (Google Sheet + API)
- **source/** — הקבצים המקוריים של המבחנים (DOCX/PDF מ-Google Drive)

## איך זה עובד

### תלמיד
1. נכנס ל-`index.html` → בוחר "כניסת תלמיד"
2. ממלא שם + כיתה + ת"ז
3. בוחר מגזר (כללי/ערבי) → מקצוע → מבחן ספציפי
4. פותר את המבחן — רדיו-באטן לאמריקאיות, textarea לפתוחות
5. מגיש → מקבל ציון חלקי מיידי + הודעה אם יש שאלות שעברו לבדיקת מורה

### מורה
1. נכנס ל-`index.html` → "כניסת מורה"
2. PIN ברירת מחדל: `2024` (ניתן לשנות ב-teacher.html)
3. דשבורד:
   - **כל ההגשות**: טבלה עם שם, כיתה, מבחן, ציון, סטטוס
   - **ממתינות לבדיקה**: פילטר לכל מה שצריך ציון ידני
   - **מחוונים**: עריכת התשובות הנכונות לכל מבחן (חד-פעמי לכל מבחן)
4. לחיצה על הגשה → מודל בדיקה עם תשובות התלמיד, ציון ידני לשאלות פתוחות, שמירת ציון סופי
5. ייצוא CSV של כל ההגשות

### חישוב ציון
- **שאלה אמריקאית עם מחוון** → מחושבת אוטומטית
- **שאלה אמריקאית ללא מחוון** → עוברת לבדיקת מורה
- **שאלה פתוחה** → תמיד לבדיקת מורה
- **ציון סופי** = ציון אוטומטי + ציונים ידניים של המורה

## הקמה (חד-פעמית)

### שלב 1: Google Sheet + Apps Script
1. sheets.google.com → יצירת גיליון חדש, שם "ort-practice-exams"
2. Extensions → Apps Script → הדבקת התוכן של `practice-exams-apps-script.js`
3. Save → הרצת `setup` → אישור הרשאות
4. Deploy → New deployment → Web app:
   - Execute as: Me
   - Who has access: Anyone
   - Deploy → העתקת URL

### שלב 2: חיבור ה-URL
- פתחי את `student.html` ואת `teacher.html`
- ב-`<script>` מצאי: `const APPS_SCRIPT_URL = '';`
- הדביקי את ה-URL בין הגרשיים בשני הקבצים

### שלב 3: פרסום ל-GitHub Pages
- commit + push → זמין ב-`meytalp-dev.github.io/ort-presentation-builder/practice-exams/`

## הוספת מבחנים חדשים

המבחן הראשון (אזרחות תשפ"ה כללי) מוכן. להוספת עוד:

### אופציה 1: ידני (מדויק ביותר)
1. בנייה של קובץ JSON חדש ב-`exams/<exam-id>.json` לפי המבנה של `civics-taspe-general.json`
2. הוספה ל-`exams/index.json` תחת המגזר+מקצוע המתאים עם `"status": "ready"`
3. במורה → טאב "מחוונים" → סימון התשובות הנכונות

### אופציה 2: לבקש עזרה
תגידי לי "תעביר לי את <שם המבחן> ל-JSON" — אקרא את ה-DOCX מ-`source/` ואבנה.

## הגדרת מחוון (תשובות נכונות)

בלי מחוון: כל שאלה עוברת לבדיקת מורה.
עם מחוון: אוטומטי.

**איך מגדירים:**
1. נכנסים ל-teacher.html כמורה
2. טאב "מחוונים"
3. לכל שאלה אמריקאית — לוחצים על א/ב/ג/ד הנכון
4. "שמור מחוון" — כל ההגשות הקיימות לאותו מבחן יחושבו מחדש אוטומטית

## מצב ללא Apps Script (זמני)

אם עוד לא הגדרת את ה-Apps Script, המערכת עובדת עם `localStorage` בלבד:
- כל הנתונים נשמרים בדפדפן של התלמיד/המורה בלבד
- לא ישותף בין מחשבים
- שימושי לבדיקות

## אבטחה — מה כדאי לדעת

- **PIN של המורה**: מאוחסן ב-HTML, קל לעקוף. למערכת ייצור — להוסיף שכבת auth בצד Apps Script.
- **נתוני תלמידים**: נשמרים ב-Google Sheet תחת חשבון Google שלך. הגיליון פרטי אלא אם שיתפת.
- **Web App Access: Anyone**: כל מי שיש לו את ה-URL יכול לשלוח הגשה. לא חמור כי אין PII רגיש.
