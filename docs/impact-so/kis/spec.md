## 1. למה עכשיו

שתי הזדמנויות מתחברות:

1. **חובת חינוך פיננסי בכיתה ט'** (משרד החינוך, פברואר 2026) — 200K מורים מחפשים תוכן לספטמבר. הקורס "פיננסקלאס" של Learni נכנס לאותו חלון. כיס היא הכלי שהקורס מסתמך עליו.

2. **חלל ריק בשוק** — אין בישראל אפליקציית **תקציב** דיגיטלית בעברית לגיל 13-18. PayBox Young היא תשלום. Pepper היא בנק (16+). תוכניות החינוך הפיננסי הן חומר לימוד, לא כלי. רייז אפ היא למבוגרים באנגלית.

הקורס מביא משתמשים. המוצר משאיר אותם.

## 2. הבעיה שאנחנו פותרים

### בעיית הנער/ה
- "אני יודע שיש לי כסף בבית, ואני לא יודע איפה הוא נעלם"
- "אני רוצה משהו ואני לא יודע איך להגיע אליו"
- "אני לא רוצה לפתוח אקסל"
- "אני לא רוצה שאמא תראה את כל מה שאני קונה"

### בעיית קהל היעד עם קשיי קשב/לקויות למידה
- תרגום חלום → תוכנית פעולה הוא **תפקוד ניהולי-מנהל** (executive function) — בדיוק הקושי המרכזי
- אקסל = עומס קוגניטיבי
- שגרות מסובכות לא נשמרות
- צריכים תוצאה גלויה, מהירה, רגשית

### בעיית הקורס פיננסקלאס
- 4 שיעורי יחידה 1 דורשים כלי דיגיטלי שתומך ב-Kakeibo + בניית תקציב + רפלקציה
- Google Sheets מוסיף עומס שלא קשור למטרת היחידה
- צריך כלי שמוכן לתלמיד שמגיע ראשון לשיעור, ולתלמיד שמגיע לבד בלילה

- חיים בעולם של Bit / PayBox / כספי הורים / עבודות קטנות

- צריכות הסבר קצר ב-spec של הקורס

## 4. אסטרטגיית התרחבות חינוכית

המודל ב-[financial-teacher-kit](../financial-teacher-kit/annual-plan.md) מציג את **המסגרת כוללת** (חיסכון אישי = רווח יזמי = תקציב פרויקט = ROI שיווקי). כיס שומרת על העיקרון:

- **לנוער כצרכן** — תקציב אישי (חיסכון לחלום)
- **לנוער כיזם** — תקציב פרויקט עם רווח (Lean Canvas Lite מובנה)
- **לימוד עתידי** — אותו DNA יחזיק לתפקידי מנהל/יזם/משווק

זה לא "פיצ'ר נוסף". זה **מסר חינוכי** שכיס מעבירה דרך הארכיטקטורה שלה: יש "תקציב אישי" ויש "תקציב פרויקט/עסק". אותם 4 שדות, מסגרת שונה.

## 5. הפיצ'רים — מבנה דו-שכבתי

### שכבה א' — מוצר נוער עצמאי (פאזה 1)

1. **Onboarding** — 3 שדות (גיל, הכנסה חודשית משוערת, יש חלום?)
2. **אשף החלום** — 7 שלבים מ-"מה אני רוצה" עד SMART Goal מבוסס
3. **רישום הוצאה** — 3 קליקים (סכום · קטגוריה · רגש)
4. **דשבורד "החלום שלי"** — קצב + השפעת כל הוצאה על החלום
5. **בונה תקציב** — 50/30/20 או Zero-Based
6. **גיבוי JSON** — ייצוא/ייבוא ידני

### שכבה ב' — שיפור לקורס פיננסקלאס (פאזה 2)

7. **תקציבי סימולציה** — 3 פרופילים מובנים (חייל משוחרר / סטודנט / מתחיל בעבודה)
8. **Lean Canvas Lite** — 4 משבצות לעסק "צד"
9. **רפלקציה Kakeibo שבועית** — 4 השאלות + פסקה
10. **"תיק התקציב" PDF** — תוצר סופי מוכן להגשה

### שכבה ג' — אחרי השקה (פאזה 3, אופציונלי)

11. **AI Coach** — ייצוא תקציב מנוקה → ChatGPT/Claude עם prompt מובנה ב-URL
12. **תזכורות עדינות** בתוך האפליקציה (in-app, לא push)
13. **ארכיון חלומות** — חלומות שהשתנו לאורך זמן
14. **סנכרון Google Drive** — גיבוי אוטומטי אופציונלי

## 6. אשף החלום — לב המוצר

זהו הפיצ'ר המבדל. שאר הפיצ'רים הם תקציב סטנדרטי; **רק כיס לוקחת מתבגר מ-"אני רוצה" ל-"אני יודע איך"**.

### 7 שלבי האשף

| # | שם | מה התלמיד עושה | רגע פדגוגי |
|---|---|---|---|
| 1 | **החלום** | טקסט חופשי + "למה זה חשוב לי" | רגש לפני מספרים |
| 2 | **המחקר** | מחפש בעצמו כמה זה עולה (גוגל/AI/חנות) | כיס לא ממלאת — התלמיד חוקר |
| 3 | **הזמן** | בוחר תאריך יעד | התחייבות לפני בדיקה |
| 4 | **בדיקת מציאות** | כיס מציגה: ₪__/חודש, ₪__/שבוע, ₪__/יום | המתמטיקה אחרי ההתחייבות |
| 5 | **רמזור** | ירוק (<20% הכנסה) / צהוב (20-40%) / אדום (>40%) | החלטה: ממשיכים או מתאימים |
| 6 | **התאמה** | 3 דרכים: לוח זמנים · היקף יעד · **הגדלת הכנסה (→ Lean Canvas)** | חיבור ליזמות, פתרון מערכתי |
| 7 | **SMART** | "אני אחסוך ₪___ עד ___ כדי ___, על ידי ___" — כפלט | המשפט הקאנוני מהקוריקולום |

### חיבור לרישום היומי

כל הוצאה שהתלמיד רושם מציגה את **ההשפעה על החלום**:
> רשמת פלאפל ₪25 → זה יום אחד פחות מהאייפון שלך.

זה לא דשבורד מצטבר אבסטרקטי. זו תזכורת ברגע ההחלטה.

### חלום אחד פעיל + ארכיון
- **חלום אחד פעיל** בלבד — לא לבלבל
- **ארכיון "חלומות שעברו בראש שלי"** — נשמר ברקע, לא בולט, חומר לרפלקציה ("מה השתנה?")

## 7. קטגוריות ותיוגים

### קטגוריה ראשית (חובה לבחור — 3 בלבד)
- **חובה** — מה שאי אפשר בלעדיו (אוכל, תחבורה לבית ספר, חוגים שלא בוחרים)
- **רצוי** — מה שנעים לי שיהיה, אבל אפשר לוותר (ספוטיפיי, ספרים, יציאות)
- **מותרות** — מה שגורם הנאה רגעית (פלאפל ברחוב, גלידה, יציאה ספונטנית)

### תגיות משניות (אופציונליות)
- **קבוע / משתנה** — לחיבור למטריצת 2×2 בשיעור 1.1
- **אישי / יזמי** — לחיבור ל-Lean Canvas (שכבת ב')
- **רגש**: 😊 מרוצה · 😐 בסדר · 😕 מתחרט — לרפלקציה

### הקטגוריות **לא** ניתנות לעריכה ב-MVP
החלטה פדגוגית. ריבוי קטגוריות = שיתוק. 3 קטגוריות = מספיק להבחנה משמעותית. תגיות נותנות גמישות בלי לפזר.

## 9. זרימת משתמש — שני מסלולים

### מסלול א' — נער/ה שמגיע/ה לבד
```
מעבר ל-kis → Onboarding (3 שדות, 90 שניות) →
  → שאלת חלום:
    "כן, יש לי חלום" → אשף החלום (5 דק') → Today
    "לא" / "עוד לא חשבתי" → Today (אשף נשאר כקריאה לפעולה)
  → רישום הוצאות → חזרה מחר.
```

### מסלול ב' — תלמיד/ה בקורס פיננסקלאס
```
שיעור 1.1 → המורה מציגה את כיס → התלמיד נכנס →
  → Onboarding → "החלום שלך" (שיעור 1.3 חוזר לכאן) →
  → רישום 14 ימים (1.1 + שיעורי בית) →
  → שיעור 1.2: צפייה בנתונים, AI חיצוני מנתח →
  → שיעור 1.3: בונה תקציב סימולציה + תקציב אישי + אשף חלום →
  → שיעור 1.4: רפלקציה + Lean Canvas + ייצוא תיק התקציב
```

**אותם מסכים, פתח כניסה שונה.** 90% מהפיצ'רים משותפים.

## 11. שפה ועיצוב — צעיר · צבעוני · תוסס

> **החלטה:** כיס **לא** משתמשת בעיצוב הרגיל של Learni (Lavender + Graphite, מינימליסטי).
> קהל היעד הוא נוער שגדל על Instagram / TikTok / Snapchat / Discord. עיצוב מינימליסטי-קלאסי מרגיש להם מזדקן, רשמי, "של ההורים".

### שפה
- עברית, RTL מלא
- גוף שני יחיד נטרלי ("מה אתה רוצה לחסוך אליו?")
- שפה מדוברת, **לא נופלת לקליל מדי** — נוער 2026 חכם לזה
- אימוג'ים: רק 3 ברגש הוצאות (😊 😐 😕). שאר הממשק — איקונים גרפיים.

### השראה ויזואלית (פלטפורמות מוכרות לנוער)
| פלטפורמה | מה לוקחים |
|---|---|
| **Instagram Stories** | גרדיאנטים חיים · glassmorphism · רקעים תוססים · big rounded |
| **TikTok** | טיפוגרפיה גדולה ובוטחת · ניגודיות גבוהה · אנרגיה |
| **Snapchat** | צהוב חזק · משחקיות · אייקונים נדיבים בגודלם |
| **Cash App** | פיננסים עם אישיות · קצב · אנימציות סיפוק |
| **Linear / Notion** | מהירות · ליטוש · קצוות חדים-מודרניים |

### פלטה
```
Background (dark default):   #0F1729  (כחול-לילה עמוק)
Background (light optional): #FAFAFA  (אופ-וייט נקי)

Brand gradient:              #8B5CF6 → #EC4899  (סגול חשמלי → ורוד חם)

Categories:
  חובה:    #06B6D4  (ציאן — Instagram cool)
  רצוי:    #FACC15  (צהוב תוסס — Snapchat-ish)
```

**Dark mode = ברירת מחדל.** Light mode = אופציה בהגדרות. נוער 2026 ב-90% מהזמן בכהה.

### טיפוגרפיה
```
Display (כותרות ענק):    Heebo Black 900  (90px-48px)
Section headers:        Heebo Bold 700   (24px-32px)
Body:                   Heebo Regular    (16px-18px)
Personal moments:       Caveat Regular   (חלום, פסקת רפלקציה — רק שם)
Numbers / amounts:      Heebo Black 900  (גדול ובולט)
```

**עיקרון:** מספרים זה הגיבור של אפליקציית תקציב. ₪2,750 ב-72px. ₪25 ההוצאה הקטנה — 32px. המספרים מצורסרים לתוך העיצוב, לא מתחבאים.

### שפה ויזואלית
- **קצוות עגולים מאוד** — 24px על כרטיסים, 16px על כפתורים, full על FAB
- **Glassmorphism** עדין על פאנלים — `backdrop-filter: blur(20px)` עם רקע חצי-שקוף
- **גרדיאנטים** — ברקעים, בכפתורי action, בלא יותר מ-2-3 מקומות בו זמנית
- **Particles / confetti** — רק ברגעי הישג (אשף הושלם · יעד נסגר · רפלקציה שבועית מלאה)
- **Bottom Navigation** — 3 איקונים: בית · הוסף (FAB מורם) · חלום
- **כפתור הוסף הוצאה** — FAB גדול, גרדיאנט, צף תחתון-ימני (RTL)

### איקונוגרפיה
- **Phosphor Icons** (Duotone לאיקונים חשובים, Regular לכלליים)
- בגודל נדיב: 32-48px על פעולות ראשיות. 24px על משניות.
- **אין** איקונים סטטיים מקובעים — hover/active מקבל תזוזה קלה

### אנימציות (חובה — הן חלק מההרגשה)
| רגע | אנימציה |
|---|---|
| מעבר בין מסכים | slide 250ms ease-out |
| הוספת הוצאה | bounce על FAB · flash צבע הקטגוריה · spring על מספר חדש בדשבורד |
| השלמת אשף חלום | confetti burst · gradient בולט · "אתה בדרך" באנימציית כתב יד (Caveat) |
| התקדמות ליעד | מד מתמלא בליווי spring · המספר עולה באנימציית counter |
| רפלקציה נשמרה | check בולט · רקע פולס · התראה רכה |

### מצב Light (אופציונלי, פאזה 1.5)

### לוגו וחתימת מותג
- שם זמני "כיס" — קצר, ישראלי
- **רעיון לוגו:** "כיס" באות קליגרפית עם זנב גרדיאנט סגול-ורוד · אופציה: סמל של כיס פתוח עם מטבע בגרדיאנט
- אלטרנטיבות אם השם משתנה: "מטמון" · "טייק" · "Coin" · "Save" · "Bag"
- **חתימת תחתון אחידה:** "מבית ImpactOS" — קטן, אפרור, רק במסך הגדרות ובאתר השיווקי. **לא** מציגים את ImpactOS במסכי המוצר היומיים. נוער לא צריך להרגיש שהוא משתמש ב"מערכת" של גופים.

## 12. ארכיטקטורה טכנית

### Stack מינימלי (פאזה 1)
- HTML / CSS / JavaScript vanilla
- אופציה: Alpine.js (3KB, ריאקטיביות בלי build step)
- Chart.js לגרפים (קל, lightweight)
- אין React/Vue/Svelte ב-MVP — overkill לסקופ הזה

### מבנה תיקיות
```
docs/learni/kis/
  spec.md                    ← מסמך זה
  app/
    index.html               ← נקודת כניסה
    css/
      main.css
      mobile.css
    js/
      storage.js             ← localStorage wrapper
      dream.js               ← אשף החלום
      expense.js             ← רישום
      budget.js              ← בונה תקציב
      dashboard.js
      export.js              ← ייצוא JSON/PDF
    components/
      modal.js
      wizard.js
      chart.js
  README.md
```

### מבנה נתונים (localStorage)
```javascript
{
  profile: { age, income_estimate, created_at },
  dream: {
    title, why_matters, target_amount,
    target_date, current_saved, status: 'active'
  },
  dreams_archive: [...],
  expenses: [
    { id, date, amount, category, tag_fixed, tag_business, emotion }
  ],
  budgets: [
    { id, name, type: 'personal'|'simulation', method: '50/30/20'|'zero-based',
      income, allocations: { ... } }
  ],
  reflections: [
    { week, kakeibo_answers: {...}, free_text }
  ],
  lean_canvas: { offer, audience, cost, price }
}
```

### PWA (מ-MVP, פאזה 1)
- `manifest.json` — שם, אייקונים, צבעי מותג, splash screen
- Service Worker — caching בסיסי, offline-first
- Installable מהדפדפן (Add to Home Screen)
- אייקונים בכל הגדלים הנדרשים

### Google Play (פאזה 2ב — אוקטובר 2026)
- אריזה דרך **Bubblewrap** (Google open-source) — מייצר APK מ-PWA
- מבוסס TWA (Trusted Web Activity) — אנדרואיד מציג את ה-PWA כאפליקציה
- עלות: $25 חד-פעמי ל-Google Play Developer Account
- דרישות: Domain verification (`assetlinks.json` ב-`kis-app.co.il`)
- אורך תהליך: ~1 שבוע פיתוח + 3-7 ימי סקירת Google
- **לא** דורש כתיבה מחדש — אותו PWA, רק נארז

### iOS App Store (פאזה 3 אופציונלי)
- אפשרי דרך **PWABuilder** של Microsoft או Capacitor
- עלות: $99/שנה ל-Apple Developer + סקירה ידנית קשוחה
- מומלץ רק אחרי הוכחה שהמוצר עובד באנדרואיד

### תשתית רב-לשונית i18n (מ-MVP)
- כל הטקסטים בקובץ נפרד `i18n/he.json` (מ-MVP)
- אין טקסטים hardcoded ב-HTML/JS
- מבנה מפתחות מקונן: `dream.wizard.step1.title`
- בעתיד: `i18n/ar.json` (RTL כמו עברית), `i18n/en.json` (LTR — צריך התאמת CSS)
- ספרייה מוצעת: tinyJS i18n או implementation מינימלי (50 שורות)
- **תרגום בפועל** — פאזה 3, רק אחרי שהקופי בעברית התייצב
