# בנק הקופי של כיס

> **המקור הסמכותי לכל טקסט באפליקציה.**
> כל ערך כאן יהפוך ל-key ב-`i18n/he.json` עם 3 גרסאות: זכר (m) · נקבה (f) · ניטרלי (n).
> אסור hardcoding טקסט בקוד.

---

## עקרונות כתיבה

- **קול:** סרקזם רך + מודעות עצמית + הבנת 5 הכאבים של נוער ישראלי
- **טון:** חברה שיורדת באהבה, לא הורה מטיף
- **מותר:** לרדת רכות על המשתמש, על האפליקציה עצמה, על המציאות
- **אסור:** ירידה משפילה, סוכרי, הומור על מצב משפחתי
- **שפה אסורה:** "אופציונלי", "פלטפורמה", "ממשק", "התראות", "דמי שירות", "דליפה", "התפוצץ"
- **שפה רצויה:** "אש", "אחי/אחותי", "וואלה", "באסה", "השתוללת", "חזרת"
- **אסור להזכיר שמות מתחרים** (Pepper, PayBox, Greenlight, GoHenry, Mintable, צעירים בפלוס). גם בהומור — זו פרסומת חינם להם וגם מציעה אלטרנטיבה. מותר להזכיר מותגים נייטרליים שלא מתחרים: AliExpress, Castro, Wolt, McDonald's, פלאפל ברחוב.

### חוק קריטי: לא לדבר על "אמא" או "אבא" ספציפית

עבור ילד/ה יתום/ה / בפנימייה / משפחת אומנה / חד-הורי — אזכור "אמא" הוא דריכה על פצע. **משתמשים תמיד ב"הורים"** (כללי) או ב"מישהו" (אם רוצים יותר רך).

## 1. Onboarding (5 מסכים)

### מסך 1 — שם

> **כיס.**
> כי "מערכת לניהול תזרים פיננסי לבני הדור הצעיר" זה שם של מסמך שאף אחד לא קרא.

### מסך 2 — גיל

> בן/בת כמה?
> אנחנו לא ביטוח לאומי. אין לנו תיק עליך.

**Validation:**
- אם < 13 או > 18: "כיס בנויה ל-13 עד 18. אבל אם זה אתה — בוא ננסה." [סבבה אני נכנס] [אני לא בגיל הזה]

### מסך 2.5 — מגדר (פנייה)

> **איך לפנות אליך?**
> [ בן ] [ בת ] [ מעדיף/ה לא לציין ]

### מסך 3 — תחקיר הכנסה (4 שאלות)

> **בא נבין כמה כסף נכנס לך לערך**
>
> זה לא בחינה. תקרבי, נחשב יחד.

**שאלה 1 — דמי כיס מההורים:**
> כמה דמי כיס מההורים בחודש?
> [ ₪0 ] [ ₪50 ] [ ₪100 ] [ ₪200 ] [ ₪500 ] [ אחר → input ]

**שאלה 2 — מתנות בחגים (חלוקה לחודש):**
> מתנות בחגים — בחגים אתה מקבל בערך?
> [ ₪0 ] [ ₪200/שנה ] [ ₪600/שנה ] [ ₪1,500/שנה ] [ אחר → input ]
>
> *(האפליקציה מחלקת ל-12 חודשים)*

**שאלה 3 — עבודה צד:**
> עובד במשהו (Wolt, בייביסיטר, חנות)?
> [ לא ] [ ₪200 ] [ ₪500 ] [ ₪1,000 ] [ ₪2,000 ] [ אחר → input ]

**שאלה 4 — אחר:**
> משהו אחר? (סבא בחג, פרס, מוצרים שמכרת)
> [ ₪0 ] [ ₪100 ] [ ₪300 ] [ אחר → input ]

**הצגה בסוף:**
> "סך הכל: **₪___ בחודש בערך.** אפשר לעדכן בכל רגע בהגדרות."

### מסך 4 — חלום

> יש משהו שאתה חוסך אליו?
> [ יש לי בראש ] [ אין, אבל אחשוב ] [ למה אני צריך חלום ]

## 6. אשף החלום — 8 שלבים

> **שינוי מהגרסה הקודמת:** 8 שלבים ולא 7. השלב הנוסף — "הוצאות חובה" — נוסף בין "מתי" ל"בדיקת מציאות". הסיבה: תלמיד צריך להבין שלא כל ההכנסה זמינה לחיסכון.
