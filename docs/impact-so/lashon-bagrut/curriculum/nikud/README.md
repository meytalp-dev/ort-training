## תקצירים מהירים — 5 תיקונים שגיליתי באימות 23.5.2026

לא להאמין למה ש-LLM "זוכר" — אלה הדברים שטעיתי בהם:

1. **קבוצת הגרוניות לעניין דגש = אהחע"ר** (5 אותיות, כולל ר'). לא רק אהח"ע.
2. **בחירת חטף** — לפי התנועה שהשווא הנע היה נושא, **לא** לפי תנועה אחרת במילה.
3. **בגרות 011281 לא דורשת** הבחנה הגייתית סגול/צירה, או זיהוי קמץ קטן בכתיב.
4. **צׇהֳרַיִם נהגה tso-ho-ra-yim** (שני קמצים קטנים, o-o), לא tza-ho.
5. **5 כללי שווא נע** אינם רשימה רשמית של האקדמיה — לנסח עם "בדרך כלל" ולא "תמיד".
