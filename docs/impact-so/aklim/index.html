איזה ממד הכי דורש התערבות החודש?
שייכות — ירידה של 0.4 נקודות מהפולס הקודם, רוב הירידה ב-י' וב-י"א. שלוש שאלות פתוחות מזכירות "אין לי עם מי לדבר בהפסקה". מומלץ לפתוח את התקופה הבאה בממד שייכות, ולכנס שיחה דחופה עם רכזת השכבה.
מה לעשות מחר בשעת חינוך של י/2?
פעילות "מי אני, מי את.ה" — 25 דקות, זוגות מתחלפים, 3 שאלות לחיבור אישי. מתאים לציון השייכות הנמוך שלהם (2.1). הוכן מערך מלא ב-PDF, נשלח אלייך עכשיו.
