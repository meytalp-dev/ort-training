# עדכון ה-Apps Script — טופס יצירת קשר → מייל למיטל

הסקריפט הפרוס היום מטפל רק בהרשמות לתפוצה. העדכון מוסיף טיפול בפניות מטופס
"יצירת קשר" באתר: שמירה בטאב "יצירת קשר" בגיליון + מייל אלייך (עם reply-to של הפונה).

**עד שהעדכון נפרס** — האתר ממשיך לעבוד: הטופס מזהה שהסקריפט ישן ונופל אוטומטית
לפתיחת תוכנת מייל (ההתנהגות הקיימת). שום פנייה לא הולכת לאיבוד.

## שלבי העדכון (2–3 דקות, פעם אחת)

1. פותחים את גיליון ההרשמות לתפוצה ב-Google Sheets.
2. **Extensions → Apps Script** (אם הסקריפט הוא פרויקט נפרד — פותחים אותו דרך script.google.com).
3. מוחקים את הקוד הקיים ומדביקים את כל התוכן של `code.gs` שבתיקייה הזו.
   - אם הסקריפט **לא** נפתח מתוך הגיליון: ממלאים את `SHEET_ID` (המזהה הארוך מכתובת הגיליון).
4. **Deploy → Manage deployments → ✏️ (עריכה) → Version: New version → Deploy.**
   - חשוב לערוך את הפריסה הקיימת ולא ליצור חדשה — כך הכתובת נשארת זהה והאתר לא צריך שינוי.
5. בפריסה הראשונה גוגל יבקש אישור הרשאות (גיליון + שליחת מייל) — לאשר.
