# היום שלך במערכת — מיפוי שימוש

כלי פולס בן 14 כרטיסים שממפה איך מנהלים, סגנים, רכזים ומורים משתמשים במערכות הפדגוגיות בבית הספר (סמארט סקול / משוב / תיק תק / כל מערכת אחרת).

## הקובץ
- `index.html` — הפולס + מסך הדיוקן
- `apps-script.js` — קוד שמירה ל-Google Sheet

## שלבי התקנה

### 1. צור Google Sheet
- שם: "מיפוי שימוש - מערכות פדגוגיות"
- העתק את ה-Sheet ID מה-URL (החלק בין `/d/` ל-`/edit`)

### 2. התקן את Apps Script
- ב-Sheet → Extensions → Apps Script
- הדבק את `apps-script.js`
- החלף `YOUR_SHEET_ID_HERE` ב-Sheet ID
- שמור (Ctrl+S)

### 3. Deploy ל-Web App
- Deploy → New deployment → Web app
- Execute as: **Me**
- Who has access: **Anyone**
- העתק את ה-Web app URL

### 4. חבר ל-HTML
- פתח את `index.html`
- מצא: `const APPS_SCRIPT_URL = '';`
- הדבק את ה-URL בין הגרשיים

### 5. דחוף ל-GitHub Pages
```bash
git add docs/school-management-venture/usage-mapping/
git commit -m "כלי מיפוי שימוש — היום שלך במערכת"
git push
```

## איך הפולס מסווג ל-9 דיוקנים

| דיוקן | תנאי |
|------|------|
| **המתחיל** | ≤2 מודולים פעילים |
| **הפרגמטי** | ≥5 פעולות מחוץ למערכת |
| **איש הקשר** | תקשורת הורים דומיננטית, תיעוד נמוך |
| **המתעד** | ציון נוכחות+ציונים גבוה (≥6) |
| **האסטרטג** | דוחות+תכנון גבוה (≥4), תיעוד נמוך |
| **המנטור** | מורה עם תקשורת+תיעוד מאוזנים |
| **השגרתי** | ≥5 מודולים פעילים + ≥45 דקות ביום |
| **הזריז** | ≤4 מודולים + ≤30 דקות ביום |
| **המסתגל** | כל השאר |
