# התקנת הסוכן היומי — סקירת משרות

זמן התקנה: ~5 דקות. כל ההתקנה פעם אחת בלבד.

## שלב 1 — צרי Google Sheet
1. פתחי [sheets.new](https://sheets.new)
2. שני שם: **סקירת משרות — מיטל**

## שלב 2 — הדביקי את הסקריפט
1. בתפריט ה-Sheet: `Extensions → Apps Script`
2. מחקי את הקוד שיש (function myFunction…)
3. העתיקי את **כל** התוכן מהקובץ `jobs-scanner-apps-script.js` והדביקי
4. שמרי (Ctrl+S) — תני שם לפרויקט: "Jobs Scanner"

## שלב 3 — הריצי setup
1. בסרגל העליון של Apps Script: בחרי `setup` ולחצי `Run`
2. גוגל תבקש הרשאות — תני אישור (ייתכן ויופיע "Advanced → Go to project (unsafe)" — זה תקין כי הסקריפט שלך)
3. תקבלי הודעה ש-3 הטאבים נוצרו

## שלב 4 — התקיני טריגר יומי
1. בחרי `installDailyTrigger` ולחצי `Run`
2. הסוכן ירוץ כל בוקר ב-06:30 שעון ישראל

## שלב 5 — Deploy כ-Web App
1. למעלה בימין: `Deploy → New deployment`
2. בגלגל הקטן: בחרי `Web app`
3. הגדרות:
   - Description: `Jobs Scanner v1`
   - Execute as: **Me**
   - Who has access: **Anyone**
4. לחצי `Deploy`
5. **העתיקי את ה-Web app URL** (משהו כמו `https://script.google.com/macros/s/AKfyc.../exec`)

## שלב 6 — חברי לדף
1. פתחי `index.html` בתיקייה הזאת
2. חפשי את השורה: `const SCAN_API_URL = '';`
3. הדביקי את ה-URL בין הגרשיים: `const SCAN_API_URL = 'https://script.google.com/...';`
4. שמרי, commit, push

## שלב 7 — בדיקה ראשונית
1. בחזרה ב-Apps Script: בחרי `runScan` → `Run`
2. ייקח כ-30 שניות. אחרי שמסיים:
   - בדקי את הטאב `jobs` ב-Sheet — אמורות להיות שורות
   - בדקי במייל (mlypeleg@gmail.com) — אמור להגיע מייל "☀ X משרות חדשות"
   - פתחי את הדף ועברי לטאב "הבוקר" — המשרות אמורות להופיע

## שינוי מילות מפתח
פתחי את הסקריפט ב-Apps Script, חפשי את `const KEYWORDS`, ערכי, שמרי.
**לא צריך deploy מחדש** — הטריגר יקרא את הגרסה החדשה אוטומטית.
