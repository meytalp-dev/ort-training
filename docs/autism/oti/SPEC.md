# אוטי — אתר מענים לאוטיזם (פיילוט)

מיקום: `docs/autism/oti/`

## מטרה
לענות על שאלה אחת של הורה: "מה המענה הנכון לילד/ה שלי עכשיו — ומה בא אחרי?"

## פרסונות (פיילוט)
- הורה צעיר (3–12) — מסגרת, אבחון, טיפולים
- הורה לבוגר (18+) — דיור, תעסוקה, צבא/של״צ, אקדמיה

## עיקרון — מסע, לא אינדקס
משתמשת נשאלת גיל + צורך, מקבלת מסלול של 3–7 מענים + "מה אחרי".

## טקסונומיה (פיילוט)
1. מסגרות חינוך
2. טיפולים ואבחון
3. שירותים לבוגרים
4. זכויות ורווחה

## מבנה רשומה
שם · קטגוריה · טווח גיל · מיקום · מודל שילוב · מימון · טלפון · אתר · תקציר · עדויות

## דפים
- `index.html` — 2 שאלות (גיל + צורך) → הפניה למסלול
- `path.html` — דף מסלול (3–7 כרטיסי מענה + מה אחרי)
- `service.html` — דף מענה בודד
- `browse.html` — חיפוש/סינון חופשי

## נתונים
`data/services.json` — 30–50 מענים מובילים (ידני + הצלבה עם צ'אט האמהות הירושלמי)
