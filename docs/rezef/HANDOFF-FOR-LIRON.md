## 🟡 אזורים רגישים ב-index.html — אם תיגעי, שמרי על המבנה

ה-JavaScript בקובץ קורא ל-ID-ים האלה. **אם תשני אותם או תסירי אותם, רצף נשבר.** את יכולה לשנות עיצוב, צבעים, פונט, אבל את המבנה הבסיסי שמרי:

```
#maanim-overlay
#maanim-panel
#maanim-content
#maanim-title
#maanim-breadcrumb
#maanim-back
#maanim-region    (select)
#maanim-kupa       (select)
```

הפונקציות `closeMaanim()`, `maanimBack()`, `renderCurrent()` — לא לשנות שמות.

`<script src="_maanim_inline.js"></script>` — חייב להישאר (זה הנתונים).

`MAANIM_RAW` (משתנה גלובלי) — הקוד שלך קורא לו. אסור להעלים.

**מה כן אפשר לעשות?**
- לשנות צבעים, פונטים, גדלים, רקעים, מרווחים
- להוסיף אנימציות (Framer Motion, CSS transitions, וכו')
- להוסיף sections חדשים סביב
- לשנות את ה-card design של כל מענה
- להוסיף filter UI / search UI / dark mode
- לשנות את ה-modal עיצובית (כל עוד שמרת על ה-ID-ים)
- לפצל את ה-CSS לקובץ נפרד

## 🤝 איך הסנכרון איתנו עובד

1. **את דוחפת לרפו שלך** ← הקישור החי שלך מתעדכן
2. **מיטל מריצה sync** ← אנחנו ממשכים את שינויי העיצוב שלך לתוך ה-fork שלנו
3. **מיטל דוחפת ל-fork** ← הקישור החי שלנו מתעדכן עם העיצוב החדש שלך + הנתונים שלנו

**אם תרצי לראות את הנתונים המעודכנים של מיטל (אחרי שהיא ניקתה את "ארצי" וכו'):**

- העתיקי לתיקייה שלך
- בחני שהעיצוב שלך עובד עם הנתונים החדשים
- **אל תדחפי את הקובץ הזה לרפו שלך** (אחרת תכבי את העריכות של מיטל בסבב הבא)
