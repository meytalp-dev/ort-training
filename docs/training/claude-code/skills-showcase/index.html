הסקיל frontend-design מוכלל בריפו

מתוך 10 הסקילים, frontend-design של Anthropic משוחרר ברישיון Apache 2.0 — אז הוא מועתק במלואו לתיקיית .claude/skills/design/frontend-design/ בריפו הזה, יחד עם קובץ LICENSE ו-NOTICE לפי דרישות הרישיון. מי שמוריד את הריפו מקבל אותו מוכן לשימוש. שאר הסקילים יש להתקין מהמקור — הוראות בסוף הדף.

איך להתקין סקיל

  1. פותחים את התיקייה הגלובלית של Claude Code: ~/.claude/skills/
  2. יוצרים תת-תיקייה עם שם הסקיל ובתוכה קובץ SKILL.md (אפשר להעתיק מ-GitHub של היוצר).
  3. מפעילים מה-CLI עם /<skill-name> — למשל /impeccable craft או /bolder.
  4. טיפ: סקיל שמוגדר user-invocable: true עולה אוטומטית ברשימת ה-slash commands. השאר נטענים כשקלוד מחליט שההקשר רלוונטי.
