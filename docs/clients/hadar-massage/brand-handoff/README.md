# 🌿 חבילת המותג של HADAR BACK — איך להשתמש

הי הדר! זו חבילת המותג שלך. היא גורמת ל-Claude Code שלך לבנות לך הכל (פוסטים, דפים, פליירים) **לפי המותג — אוטומטית**, בלי שתצטרכי להסביר בכל פעם מאיזה צבע או פונט.

## מה יש בתיקייה
- **CLAUDE.md** — קובץ ההנחיות. זה הקובץ הקסום: Claude Code קורא אותו לבד.
- **brand-kit.html** — ספר המותג המלא. לחיצה כפולה פותחת אותו בדפדפן — שם רואים הכל ויזואלית.
- **logo.svg** — הלוגו שלך לשימוש חוזר.

## איך מתקינים (פעם אחת, 2 דקות)
1. שמרי את **כל התיקייה הזו** בתוך התיקייה שבה את עובדת עם Claude Code (תיקיית הפרויקט שלך).
   - אם אין לך עדיין תיקיית פרויקט — צרי תיקייה חדשה (למשל `hadar-brand`) ושימי בה את הקבצים.
2. זהו. בפעם הבאה שתפתחי את Claude Code בתיקייה הזו — הוא כבר מכיר את המותג שלך.

## איך משתמשים
פשוט מבקשים. לדוגמה:
- *"תכין לי פוסט לאינסטגרם על עיסוי רפואי לכאבי גב אחרי לידה."*
- *"תעצב לי שובר מתנה."*
- *"תכתוב לי כיתוב לסטורי על שחרור עומס מהשרירים."*

Claude Code כבר ישתמש בצבעים, בפונט, בלוגו ובסגנון הדיבור שלך — בלי שתסבירי.

## הלוגו האמיתי שלך
בקובץ יש גרסה זמנית של הלוגו. כשיהיה לך קובץ הלוגו המקורי (PNG או SVG):
- שמרי אותו בתיקייה בשם **logo.png**
- ואם יש גרסה לבנה לרקע כהה — **logo-white.png**

וזהו — Claude Code ישתמש בלוגו האמיתי שלך.
