# מותג HADAR BACK — הנחיות ל-Claude Code

> קובץ זה נקרא אוטומטית על ידי Claude Code. **בכל פעם שאתה בונה תוצר חזותי עבור הדר** (פוסט, סטורי, פלייר, דף, מצגת, כרטיס, שובר) — החל את המותג הזה בלי שיבקשו ממך.

---

## מי המותג

**HADAR BACK · הדר בק** — מטפלת בעיסוי לנשים בלבד, באר שבע.
**עיסוי ממוקד תנועה ותפקוד** (גב, עמוד שדרה, יציבה, שחרור עומס) — לא פינוק.

- **תגית רשמית (אנגלית):** BACK TO MOTION
- **תגית בעברית:** מטיפול לתנועה, מתנועה לחיים
- **דסקריפטור:** טיפולים מותאמים אישית · באר שבע · לנשים בלבד

**רעיון המותג:** משחק מילים — BACK = בק (שם המשפחה) = הגב / עמוד השדרה. הלוגו (מונוגרם HB) משלב עמוד שדרה. "BACK TO MOTION" = גם "חזרה לתנועה" וגם "הגב בתנועה".
