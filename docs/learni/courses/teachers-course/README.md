## תוצרי הקורס לבוגרת

בסוף 15 המפגשים, כל מורה.ה תצא עם:

1. **מפת כלים אישית** — מה משתמש למה
2. **ספריית פרומפטים אישית** — 5+ פרומפטים שעובדים
3. **NotebookLM פעיל** עם בסיס ידע אישי-מקצועי
4. **Custom GPT אישי** — סוכן שמבצע משימה חוזרת
5. **סט ויזואלי** — לוגו אישי / מצגות ייחודיות / תמונות לשיעורים
6. **3 זרימות עבודה מאוטומטות** — שחוסכות 5+ שעות שבועיות
7. **אתר אישי** שנבנה ב-Claude Code
8. **פרויקט גמר** מקצועי
9. **יחידת לימוד דיפרנציאלית** מוכנה ללמד
10. **מבחן או רובריקה** עם AI
11. **3 מיילים מקצועיים להורים** — כתובים עם AI
12. **יחידת לימוד שלמה** משולבת AI
13. **תוכנית הטמעה אישית** של 90 יום בבית הספר
14. **תעודה מאושרת לגמול**

## עקרונות פדגוגיים

1. **כל מפגש = תוצר אמיתי שיכול להיכנס לכיתה מחר.**
2. **חיסכון בזמן הוא מטרה ראשית** — מורה שלא חוסכת זמן לא תמשיך.
3. **אתיקה פדגוגית מועצמת** — משוב, פרטיות, גבולות.
4. **קבוצת WhatsApp פעילה** — שיתוף הצלחות וכשלים.
5. **שעורי בית = "הבא משימה אמיתית מהשבוע"**, לא תרגיל מלאכותי.
