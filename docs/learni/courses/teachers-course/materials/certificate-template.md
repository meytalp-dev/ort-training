## QR Code — מה הוא מוביל אליו

הקישור ב-QR מוביל ל**פורטפוליו אישי של הבוגרת:**

```
URL: learni.ai/portfolio/[meytal-graduate-id]

תוכן הפורטפוליו:
- שם + תמונה
- 3 פרויקטים מהקורס (נבחרים ע"י הבוגרת)
- חוברת המסע (מילוי אישי)
- תעודות נוספות
- קישורים מקצועיים (LinkedIn, אתר אישי)
```

זה מאפשר לבוגרת לשתף את ההישג בעולם המקצועי — לא רק "תעודה במגירה".

## תהליך הענקת התעודה

### לפני יום ההצגה
1. למלא את הפרטים האישיים בכל תעודה
2. להדפיס בנייר איכותי (200 גרם +)
3. לעטוף בקלסר / נרתיק יפה
4. לייצר את הקישורים האישיים לפורטפוליו

### ביום ההצגה
1. אחרי כל הצגה — אישור ההגעה לסוף הקורס
2. טקס תעודות מובנה: כל בוגרת, משפט אישי, תעודה, צילום
3. צילום קבוצתי
4. שיתוף בקבוצת WhatsApp

### אחרי יום ההצגה
1. שליחת תעודה דיגיטלית במייל
2. שליחת קישור לפורטפוליו
3. הודעה רשמית למורה / רכזת השתלמויות בבית הספר
4. דיווח לפסג"ה (אם מסלול גמול)
