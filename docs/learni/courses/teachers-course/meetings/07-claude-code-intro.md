**מטרת-על:** המורות יוצאות עם אתר אישי חי שבנו עם Claude Code — תוצר ראשון בלי כתיבת קוד.

## מטרות מפורטות

- לבנות אתר עמוד אחד אישי

זה המפגש הקריטי בקורס. **רוב המורות יחשבו שזה לא בשבילן — "אני לא טכנית".**
התפקיד שלי: לפרק את ההגנה הזו. להראות שאם הן יודעות לכתוב WhatsApp, הן יודעות Claude Code.

**זמן ההתקנה הוא הסיכון הגדול ביותר.** להגיע מוכנה עם:
- 2–3 קבצי הוראות התקנה לשתי מערכות (Mac/Windows)
- חשבון API מוכן או חיבור לחשבון Claude Pro של כל אחת
- תיקיית עבודה מוכנה לכל מורה

## מבנה מפגש

### 0:00–0:15 | פתיחה — "5 דקות, אתר חי"

**הוראה לעצמי:**

עם השעון הקבוע על המסך:
1. פותחת Claude Code
2. כותבת: "תבני לי אתר עמוד אחד עליי כמורה ללשון. כותרת, תיאור, רשימת ספרים מומלצים. סגנון: נעים, נקי, פסטל."
3. ה-AI חושב 30 שניות. כותב קוד. מתקן. בונה.
4. אחרי 4 דקות — האתר מוכן בדפדפן. עם כפתורים, עם תמונות.

המורות שותקות. ואז מתחילות לדבר ביחד.

**שאלה מובילה:** "מה היה קורה אם כל אחת יכולה לבנות תוכנה?"

---

### 0:15–0:35 | מודל מנטלי

**שקף 1: מה זה Claude Code**

```
ChatGPT       |  עונה לך
Claude        |  עונה לך
Claude Code   |  עושה בשבילך
```

הוא לא נותן עצות. הוא **בונה**.
- פותח קבצים, קורא, כותב
- מתקין תוכנות שצריך
- בודק שזה עובד
- מתקן את הטעויות שלו

**שקף 2: כלל הזהב**

> **"AI הוא עובד מאוד חכם בלי הקשר. תפקידי לתת לו הקשר."**

לא לבקש "תכין משהו טוב". לבקש:
```
תכין אתר אישי עליי.
אני מורה ללשון בכיתות י-יב.
הסגנון: נעים, פסטל, עברית.
תכלול: כותרת, תיאור עליי, 3 ספרים שאני מלמדת.
```

**שקף 3: מתי כן ומתי לא Claude Code**

```
✅ מתאים ל:
- אתר אישי / כיתתי / פרויקטלי
- כלי קטן (מחולל / חידון)
- אוטומציה של משהו
- ניתוח קבצים והוצאת תובנות

❌ לא מתאים ל:
- שיחת ייעוץ פדגוגי (Claude רגיל יותר טוב)
- כתיבת מאמר ארוך (Claude/ChatGPT)
- יצירת תמונה (Gemini/Pomelli)
```

**שקף 4: מה הולך לקרות עכשיו**

> "אנחנו הולכות להתקין יחד. כל אחת. במחשב שלה. שלה.
> ואחרי שעה — לכולן יהיה אתר חי.
>
> אל תפחדי מהטרמינל. הוא רק חלון שמדבר עם המחשב."

---

### 0:35–1:25 | Hands-On — התקנה ובנייה משותפת

**שלב 1 (15 דק'): התקנה**

מסך משותף — אני מקרינה ומדגימה. כולן עוקבות שלב-שלב.

1. **התקנת Node.js** (אם אין)
2. **התקנת Claude Code** — שורת פקודה אחת
3. **התחברות לחשבון Claude Pro**
4. **פתיחת תיקייה ראשונה**

> **מה לעשות אם מורה תקועה:** עצור את הקבוצה. תעזור לה. **אל תמשיך עם מורה אחת מאחור.**

**שלב 2 (10 דק'): השיחה הראשונה עם Claude Code**

כל מורה כותבת בטרמינל פקודה ראשונה:
```
Hello! I'd like you to introduce yourself.
```

הוא עונה. הן רואות שזה עובד. הקסם מתחיל.

**שלב 3 (25 דק'): בניית אתר אישי**

כל מורה כותבת פרומפט מותאם:
```
תבני לי אתר עמוד אחד עליי כמורה ל-[המקצוע שלי].
תכלול:
- כותרת עם השם שלי
- תיאור עליי בעברית (2 משפטים)
- 3 דברים שמעניינים אותי במקצוע
- צבעים: [פלטה אהובה]
- סגנון: נעים, נקי, מודרני

תפתחי את האתר בדפדפן כשסיימת.
```

Claude Code עובד. בונה. פותח.
**אסור להתערב.** רק להגיד למורה: "תבני אמון. תני לו לעשות."

אם משהו לא עובד — אומרים לו:
```
האתר לא נראה כמו שרציתי. הבעיה: __________
תקני בבקשה.
```

הוא מתקן.

**שלב 4 (10 דק'): שיפור אישי**

כל מורה מבקשת שיפור אחד:
- הוספת תמונה
- שינוי צבעים
- הוספת כפתור / טופס
- הוספת רשימה

---

### 1:25–1:40 | שיתוף — "האתר שבניתי"

כל מורה פותחת את האתר שלה. מציגה.
הקבוצה צופה. אני מצלמת מסך של כל אחד (באישור).

**הרגע הזה הוא קסם.** מורה ש"לא טכנית" — בנתה אתר שעובד.

---

### 1:40–1:55 | רגע אתי — "מי הבעלים על קוד שיצר AI?"

**דיון פתוח:**

1. **הקוד שלי?**
   חוקית — כן. את שכרת את ה-AI כעובד. מה שיצר — שלך.

2. **מה אם השתמשתי בקוד פתוח באמצע?**
   צריך לציין מקור. להישמר ברישיונות (MIT, GPL וכו').

3. **מה אסור לבנות?**
   - מערכות שמטפלות בנתונים אישיים של תלמידים בלי אישור
   - אתרים שמתחזים לאחרים
   - כלים שמכוונים לפעילות לא חוקית

4. **מתי לכתוב "נבנה ב-AI"?**
   - אם זה תיק עבודות אקדמי — חובה
   - אם זה אתר אישי — לא חובה, אבל נחמד
   - אם זה לקוח משלם — צריך לדבר על זה מראש
