הכל במקום אחד

קווטרט = הקטלוג המלא של כל מה שבנינו תחת אורט בית הערבה. כל מערכת עם הכאב שהיא פותרת, התהליך מאחוריה, והטכנולוגיה שמניעה אותה.

פדגוגיה
