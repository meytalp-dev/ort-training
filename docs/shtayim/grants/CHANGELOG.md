# שינויים במערכת גיוס משאבים — סיכום לירון

## המערכת המקורית (של לירון)
`docs/shtayim/grants/index.html` — קובץ אחד עם כל הנתונים hardcoded בתוך ה-HTML.

## מה נוסף — 5 קבצים חדשים

### 1. engine.js — מנוע נתונים דינמי
**מה עושה:** טוען נתונים מקובץ JSON ומציג אותם בדף. במקום נתונים קשיחים ב-HTML, הכל נטען דינמית.
- `?org=demo` → טוען מ-demo.json
- `?org=hoppa` → טוען מ-hoppa.json
- מרנדר: דשבורד (KPIs, דדליינים, התאמה), טבלאות (קולות, קרנות, הגשות), פרויקטים, תקציב, מסמכים, שותפים, הגדרות
- empty states — הודעות ברורות כשאין נתונים ("אין הגשות עדיין")
- אחוזי התאמה עם הסבר גלוי (לא tooltip)

### 2. content-gen.js — מחולל תוכן חכם
**מה עושה:** מוסיף 3 יכולות חדשות למערכת:

**א. מחקר קרן (שלב 3 בתרשים זרימה)**
- כפתור "חקור" ליד כל קרן בטבלת קרנות
- פותח כרטיס עם: פרטי הקרן, לינקי חיפוש (Google, GuideStar, אתר הקרן), שאלות מנחות למחקר, שדה לשמירת ממצאים

**ב. כתיבת הגשות חכמה (שלב 5)**
- בורר קול קורא מרשימת הקולות הקוראים
- 5 כפתורי מילוי מהיר: הצעת פרויקט, דוח אימפקט, מכתב פנייה, נימוק תקציב, מכתב תודה
- התבניות ממולאות אוטומטית מנתוני העמותה (שם, תחומים, אזור, מוטבים, פרויקטים, תקציב)
- כפתור "שמור הגשה" שמוסיף לטבלת ההגשות

**ג. צ'קליסט מסמכים (שלב 6)**
- 10 מסמכים נדרשים עם סימון חובה (*): ניהול תקין, דוח כספי, רישום, תקנון, פרוטוקול, המלצות, הערכה, תקציב, קו"ח, ביטוח
- צ'קבוקס לסימון מוכן/חסר
- מונה התקדמות + התראה על מסמכים קריטיים חסרים

### 3. apps-script.js — Google Apps Script
**מה עושה:** מחבר את המערכת ל-Google Sheet לשמירת נתונים.
- **Sheet:** "שתיים — גיוס משאבים | הופה"
- **Sheet ID:** 1MaOXuFr9bueGJj-xP1JxmV24ioZ_jXSEcWZRy-4GoPE
- **7 גיליונות:** פרופיל, קולות_קוראים, קרנות, הגשות, פרויקטים, תקציב, checklist
- **API:** getAll, getCalls, getFunds, saveCalls, saveSubmission, saveChecklist, saveFundNotes
- **הערה:** כרגע יש בעיית CORS — הדפדפן לא יכול לקרוא מ-Sheet ישירות. הנתונים נטענים מ-JSON. הכתיבה ל-Sheet עובדת דרך image beacon.

### 4. hoppa.json — נתוני הופה
כל הנתונים של הופה בקובץ אחד:
- פרופיל (לירון גולן, תחומים, אזור)
- 7 קולות קוראים (מהסריקה המקורית)
- 11 קרנות
- 3 הגשות, 5 פרויקטים, 4 שותפים
- תקציב, מסמכים, אימפקט
- קולות שנסגרו (3), קרנות בהזמנה (5)

### 5. demo.json — נתוני דמו
נתוני דוגמה עם "עמותת הדגמה" — לא לירון.

## שינויים ב-index.html

### מה השתנה:
1. **21 IDs נוספו** לאלמנטים דינמיים (dashKpis, callsTable, submissionsTable, projectsGrid, fundsTable, budgetTable, documentsContainer, impactKpis, partnersTable, settingsFields, ועוד)
2. **הנתונים ה-hardcoded הוסרו** — כל הטבלאות ריקות, engine.js ממלא אותם
3. **"AI" הוחלף ב-"ניתוח והתאמה"** — בסיידבר, בכותרות, בכפתורים
4. **סיידבר מפושט** — 7 דפים גלויים + "עוד 5 דפים" toggle
5. **כפתור "הוסף קול קורא"** — מחובר לשמירה (לא רק סוגר modal)
6. **הכותרת** שונתה ל-"מערכת גיוס משאבים — הופה"
7. **engine.js ו-content-gen.js** נטענים בסוף הדף

### מה לא השתנה:
- כל ה-CSS (עיצוב, צבעים, responsive)
- מבנה הדפים (12 pages)
- הלוגיקה של ניווט (showPage)
- מחולל התוכן המקורי (7 תבניות, parsePrompt, tone chips)
- ניתוח AI המקורי (runAiAnalysis, runAiWrite)
- מודל הוספת קול קורא
- קוד file drag & drop

## סוכן סריקה (/scan-grants)

**מה עושה:** מריץ 2 סוכנים במקביל (Perplexity + WebSearch) שמחפשים קולות קוראים רלוונטיים לעמותה.

**תוצאות:** 22 קולות קוראים אמיתיים נמצאו מ-35 מקורות, כולל:
- ביטוח לאומי (3 קולות, דדליין 30.4)
- הקרן לעידוד יוזמות חינוכיות (דדליין 7.5)
- ועדת העזבונות 2026
- משרד ראש הממשלה
- שפ"י, Google.org, JUF, רוטשילד
- קרן שאשוא, קרן גנדיר (ממתינים למחזור)

**סוכן מתוזמן:** רץ כל ראשון וחמישי ב-7:00 בוקר (Routine ID: trig_01LvA9d931yr6xEgEq5XSFkV)

## איך לירון מטמיעה את השינויים

### אפשרות א — להשתמש במערכת החדשה כמו שהיא
הלינק: https://meytalp-dev.github.io/ort-training/shtayim/grants/?org=hoppa
- לעדכן את hoppa.json עם הנתונים האמיתיים שלה
- הכל עובד מ-GitHub Pages

### אפשרות ב — להטמיע את השינויים במערכת המקורית שלה
1. להעתיק את 3 הקבצים החדשים (engine.js, content-gen.js, apps-script.js) לתיקייה שלה
2. להוסיף את 21 ה-IDs ל-HTML שלה (ראי רשימה למעלה)
3. להוסיף `<script src="engine.js"></script>` ו-`<script src="content-gen.js"></script>` לפני `</body>`
4. להכין JSON עם הנתונים שלה (לפי המבנה של hoppa.json)

### אפשרות ג — לשלב את שתיהן
להשאיר את המערכת המקורית עם כל הנתונים שאספה, ולהוסיף רק את הפיצ'רים החדשים:
- צ'קליסט מסמכים (content-gen.js → enhanceDocumentsChecklist)
- מחקר קרנות (content-gen.js → enhanceFundsResearch)
- מילוי מהיר במחולל תוכן (content-gen.js → enhanceContentGenerator)
