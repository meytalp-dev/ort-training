# סקיל — תמונה/סרטון מלווה מ-Google Flow

## מצבי עבודה

| מצב | פקודה | שלבים |
|---|---|---|
| **תמונה** | `/flow-video image` או `/flow-video תמונה` | Nano Banana → Imagen 4 |
| **סרטון** | `/flow-video` (ברירת מחדל) | Nano Banana → Imagen 4 → Animate → Scene Maker |

אם מייטל לא ציינה מצב — לשאול: "תמונה מלווה או סרטון מלא?"

## מתי מפעילים
כשמייטל רוצה ליצור תמונה או סרטון מלווה לתוכן (פוסט, מצגת, טיפ, אינפוגרפיקה) באמצעות Google Flow.

## קלט
מייטל נותנת אחד מהבאים:
- **נושא חופשי**: "סרטון על כלי AI לניהול זמן" / "תמונה לפוסט על Gamma"
- **תוכן קיים**: "סרטון למצגת CapCut" / "תמונה לטיפ היומי"
- **רעיון מדשבורד התוכן**: "סרטון לפוסט שבנינו על Gamma"

## תהליך — 4 שלבים

### שלב 0 — ניתוח הנושא
1. קרא את הנושא/תוכן שמייטל נתנה
2. זהה את ה**מושג המרכזי** — מה הדימוי הויזואלי שמייצג את הנושא
3. זהה את **הסצנה** — באיזו סביבה הדימוי צריך להופיע
4. זהה את **הסגירה** — מה הסוף הנכון לסרטון

---

## מצב תמונה — 2 שלבים בלבד

אם מייטל ביקשה מצב תמונה, הצג רק 2 פרומפטים:

```
╔══════════════════════════════════════════════════════════════╗
║  שלב 1 — Nano Banana (יצירת תמונה)                         ║
╠══════════════════════════════════════════════════════════════╣
║  פרומפט (עברית):                                            ║
║  [פרומפט מותאם לנושא — תיאור חזותי עשיר, 1-2 משפטים]       ║
╠══════════════════════════════════════════════════════════════╣
║  שלב 2 — Imagen 4 (שינוי סצנה) — אופציונלי                 ║
╠══════════════════════════════════════════════════════════════╣
║  פרומפט (אנגלית):                                           ║
║  "What do you want to change?" →                             ║
║  [סצנה מותאמת]                                               ║
╚══════════════════════════════════════════════════════════════╝
```

אחרי אישור — פתח Flow, הנחה את מייטל בשלב 1 ו-2 (כמו במצב סרטון), ואז שמור:
- `[topic]-nano-banana.jpeg` — התמונה המקורית
- `[topic]-imagen-scene.jpeg` — התמונה בסצנה (אם ביקשה שלב 2)

עבור ישר לשלב 4 — שמירה וארגון.

## מצב סרטון — 4 שלבים מלאים

### שלב 1 — הכנת 4 פרומפטים

הצג למייטל טבלה עם 4 פרומפטים מוכנים:

```
╔══════════════════════════════════════════════════════════════╗
║  שלב 1 — Nano Banana (יצירת תמונה)                         ║
╠══════════════════════════════════════════════════════════════╣
║  פרומפט (עברית):                                            ║
║  [פרומפט מותאם לנושא — תיאור חזותי עשיר, 1-2 משפטים]       ║
╠══════════════════════════════════════════════════════════════╣
║  שלב 2 — Imagen 4 (שינוי סצנה)                              ║
╠══════════════════════════════════════════════════════════════╣
║  פרומפט (אנגלית):                                           ║
║  "What do you want to change?" →                             ║
║  [סצנה מותאמת — כיתה/משרד/סטודיו/בית קפה וכו']             ║
╠══════════════════════════════════════════════════════════════╣
║  שלב 3 — Animate (Veo)                                      ║
╠══════════════════════════════════════════════════════════════╣
║  פעולה: תפריט 3 נקודות → Animate                            ║
║  (אוטומטי, בלי פרומפט)                                      ║
╠══════════════════════════════════════════════════════════════╣
║  שלב 4 — Scene Maker (חיבור סצנות)                          ║
╠══════════════════════════════════════════════════════════════╣
║  סדר סצנות:                                                 ║
║  Start: [תמונה מקורית / סרטון 1]                            ║
║  End: [סרטון animate]                                        ║
║                                                              ║
║  פרומפט סיום (עברית):                                       ║
║  [פרומפט לסצנת סגירה מותאמת לנושא]                          ║
╚══════════════════════════════════════════════════════════════╝
```

### כללים לכתיבת פרומפטים

**Nano Banana (עברית):**
- תיאור חזותי מפורט ב-1-2 משפטים
- שימוש במילות תיאור עשירות: "זוהר", "מתפרק", "צף", "נוצץ"
- דוגמה: "נורה זוהרת מתפרקת לחלקיקים צבעוניים על רקע כהה"
- מותאם לנושא — לא תמיד נורה! חשוב על מטאפורה ויזואלית

**Imagen 4 (אנגלית):**
- משפט קצר שמתאר רק את השינוי בסצנה
- דוגמאות: "classroom setting", "modern office with screens", "coffee shop with warm lighting"
- לא לשנות את הדמות עצמה — רק את הסביבה

**Scene Maker — סיום:**
- תמיד בעברית
- פרומפט שמתאר דעיכה/סגירה מותאמת לנושא
- דוגמה: "הכל נעלם לאט, רקע לבן נקי עם נקודת אור זהובה קטנה במרכז שדועכת"
- הסגירה צריכה להרגיש כמו סוף — לא עוד סצנה

### שלב 2 — אישור ופתיחת Flow

1. שאל את מייטל אם הפרומפטים טובים או שהיא רוצה לשנות
2. אחרי אישור — פתח את Google Flow בדפדפן:

```
start "" "https://labs.google/fx/tools/flow"
```

3. הצג הנחיה ברורה:

```
שלב 1 מתוך 4 — Nano Banana
━━━━━━━━━━━━━━━━━━━━━━━━━━━
הדביקי את הפרומפט הזה ב-Flow:

[הפרומפט]

→ לחצי Generate
→ בחרי את התוצאה הכי טובה
→ הורידי (Download → 1)
→ שמרי ב-Downloads ואמרי לי "מוכן"
```

### שלב 3 — ליווי שלב-שלב

אחרי כל "מוכן" של מייטל, עבור לשלב הבא עם הנחיה ברורה:

**אחרי Nano Banana:**
```
שלב 2 מתוך 4 — Imagen 4
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. לחצי על התמונה שיצרת
2. לחצי "What do you want to change?"
3. כתבי: [הפרומפט]
4. הורידי את התוצאה
→ אמרי "מוכן"
```

**אחרי Imagen 4:**
```
שלב 3 מתוך 4 — Animate (Veo)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. חזרי לתמונה המקורית (של Nano Banana)
2. לחצי על 3 נקודות (⋮)
3. בחרי Animate
4. חכי ל-Generate (עד דקה)
5. הורידי: 720p Original Size
→ אמרי "מוכן"
```

**אחרי Animate:**
```
שלב 4 מתוך 4 — Scene Maker
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. לחצי על Scene Maker (למעלה)
2. גררי לתוך Start: [הסרטון/תמונה שנבחרו]
3. גררי לתוך End: [הסרטון/תמונה שנבחרו]
4. לחצי Generate
5. הוסיפי סצנת סיום עם הפרומפט:
   [פרומפט הסיום]
6. הורידי את הסרטון הסופי
→ אמרי "מוכן"
```

### שלב 4 — שמירה וארגון

1. שאל מייטל לאיזו תיקייה (לפי כלל הפרויקט — תמיד לשאול!)
2. שמור את כל הקבצים:
   - `[topic]-nano-banana.jpeg` — התמונה המקורית
   - `[topic]-imagen-scene.jpeg` — התמונה בסצנה
   - `[topic]-animate.mp4` — הסרטון
   - `[topic]-final.mp4` — הסרטון הסופי מ-Scene Maker
3. אם התוכן קשור לפוסט בדשבורד — עדכן את הקישור בדשבורד

### שלב 5 — סיכום

הצג סיכום עם:
- תמונות ממוזערות של כל שלב
- קישור לקבצים ששמרנו
- הצעה לשימוש: "הסרטון מוכן לפוסט / למצגת / לרילס"

## מטאפורות ויזואליות לפי קטגוריות

כדי לחסוך זמן, הנה מטאפורות ויזואליות מוכנות לפי סוגי תוכן:

| קטגוריה | מטאפורה ויזואלית | סצנה מומלצת |
|---|---|---|
| כלי AI חדש | פריזמה שמפצלת אור לצבעים | סטודיו מעצבים |
| טיפ יומי | נורה שנדלקת | שולחן עבודה מינימליסטי |
| מצגת הדרכה | ספר שנפתח ודפים עפים | כיתת לימוד מודרנית |
| יזמות / סטארטאפ | רקטה שממריאה | עיר בלילה |
| ניהול / פרודוקטיביות | שעון חול עם חלקיקים זהובים | משרד מסודר |
| שיווק | מגפון שמשחרר ניצוצות | במה עם אורות |
| חינוך כללי | גלובוס מאיר | חלל פתוח עם שמיים |
| Claude Code / AI | מסך קוד עם שורות זוהרות | סביבת עבודה טכנולוגית |
| סדנה / וובינר | יד שמציירת על קנבס | סטודיו אמנות |

## מגבלות לזכור
- Nano Banana — עברית עובדת מצוין
- Imagen 4 — פרומפט באנגלית עדיף
- Animate — עד 8 שניות
- Scene Maker — רק Start + End, לא אמצע
- כל generate שורף קרדיטים (50/יום בחינם)
- Scene Maker נתקע לפעמים — refresh ולנסות שוב
