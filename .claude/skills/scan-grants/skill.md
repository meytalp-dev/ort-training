# סוכן סריקת קולות קוראים — שתיים

סורק את הרשת לקולות קוראים רלוונטיים לעמותה, מריץ 2 סוכנים במקביל, ומעדכן את ה-Sheet.

## הגדרות

```
APPS_SCRIPT_URL = https://script.google.com/macros/s/AKfycbzl7LLZIXFtFBXN8b3K0VBXZMoPzAYwokbPgdVU-WLVHr20i_Pbng9Sb94X8FOkY89m/exec
SHEET_ID = 1MaOXuFr9bueGJj-xP1JxmV24ioZ_jXSEcWZRy-4GoPE
```

## תהליך

### שלב 1 — טעינת פרופיל העמותה
קרא מה-Sheet את פרופיל העמותה (action=getProfile) כדי לדעת מה לחפש:
- תחומי פעילות
- אזור גאוגרפי
- אוכלוסיות יעד
- גודל העמותה

### שלב 2 — הרצת 2 סוכנים במקביל
הרץ **בו-זמנית** שני סוכנים עם Agent tool:

**סוכן A — Perplexity (חיפוש עומק)**
השתמש בסקיל perplexity-search לחפש:
- קולות קוראים פתוחים בישראל בתחומי העמותה
- חפש בעברית ובאנגלית
- חפש ספציפית את כל המקורות הבאים:
  - משרדי ממשלה: משרד החינוך, שפ"י, משרד הרווחה, המשרד לפיתוח הנגב, ביטוח לאומי, אתר התמיכות הממשלתי
  - קרנות: ברנקו וייס, רשי, גנדיר, שוסטרמן, קרב, מנדל, יד הנדיב, לאוטמן, ברכה, פוסן, שעשוע
  - בינלאומי: JDC, NIF, Hadassah Foundation, Google.org
  - אגרגטורים: GuideStar, ezvonot.com, שתיל

**סוכן B — WebSearch (חיפוש רוחב)**
השתמש ב-WebSearch tool לחפש:
- "קול קורא" + תחומי העמותה + שנה נוכחית
- "call for proposals" Israel + education/youth
- חפש באתרים ספציפיים: gov.il, guidestar.org.il, btl.gov.il
- חפש גם "מכרז" + "עמותות" + תחומי העמותה

לכל קול קורא שנמצא, תעד:
- שם
- מקור/קרן
- דדליין
- סכום
- תנאי סף
- לינק
- סטטוס (open/pending/closed)
- אחוז התאמה (0-100) לפי הפרופיל

### שלב 3 — מיזוג והשוואה
1. איחוד תוצאות משני הסוכנים (הסרת כפילויות לפי שם+מקור)
2. סימון מה ייחודי לכל סוכן (מה שרק A מצא, מה שרק B מצא)
3. חישוב ציון Recall: כמה חפיפה בין הסוכנים
4. סינון: הסרת קולות שנסגרו, לא רלוונטיים, או עם התאמה < 30%

### שלב 4 — כתיבה ל-Sheet
שלח POST ל-APPS_SCRIPT_URL עם:
```json
{
  "action": "saveCalls",
  "calls": [
    {
      "name": "...",
      "source": "...",
      "deadline": "...",
      "match": 85,
      "status": "open",
      "link": "https://...",
      "eligibility": "...",
      "amount": "...",
      "category": "ממשלתי/קרן/בינלאומי",
      "notes": "..."
    }
  ]
}
```

השתמש ב-Bash עם curl לשליחת הנתונים.
